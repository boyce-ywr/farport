# 连续编辑与即时语言切换

- 发现日期：2026-10-15；严重程度：中，影响连续操作体验。
- 范围：文本编辑器、应用界面语言和状态栏时间。
- 修复提交：见本文件首次引入的 Git 提交。

## 原有问题

编辑器保存成功后直接关闭窗口。语言设置虽然保存了，但翻译模块用静态常量读取启动时的语言，运行中不会改变；关闭窗口并不等于退出应用。

原生回归分别复现了“Cmd+S 后编辑窗口关闭”和“设置简体中文后仍使用英文”，不是只检查按钮是否存在。

## 修改

- 保存后保留编辑器，显示约两秒的“已保存”，再继续编辑。保存期间禁止重复写入和修改正文。
- 增加保存、撤销、重做、剪切、复制、粘贴、全选按钮及快捷键；使用独立的原生文本撤销管理器。保存只结束当前输入合并，不清空撤销历史。
- 撤销/重做完成后从原生文本控件同步编辑缓冲区。回归曾发现控件已恢复到 27 个字符、缓冲区仍为 35 个字符，导致误报未保存甚至写回被撤销的内容；现在以实际文本同步保存状态，并检查撤销后的落盘结果。
- 每次成功保存后记录新的文件属性和内容，作为下一次冲突校验基准。保存失败保留草稿和原基准，关闭时只检查最近一次成功保存之后的修改。
- 语言改为线程安全、可观察的运行时状态。设置自动保存并立即通知界面刷新，不通过改变视图标识来重建终端或编辑器。
- 隔离验收的语言偏好使用独立存储域，避免测试期间切换语言覆盖正在使用的应用设置。
- 终端状态改为保存稳定文案键、显示时翻译；隧道模式的选择值也使用稳定键，避免切换语言后误把本地转发当作其他模式。
- 右下角增加本机时间 `HH:mm`，每分钟更新，等宽数字和固定占位不挤压状态栏。

已有历史消息、远端程序输出、文件内容和自定义名称不重新翻译；系统对话框遵循 macOS 语言。原子重命名前的检查并不等于跨客户端文件锁，原有 SFTP 边界保持不变。

## 验证

- `bash scripts/check-editor.sh --ssh`：中文和英文、本机和隔离 SSH，各验证连续 Cmd+S 保存、真实按钮点击、保存后撤销/重做、剪贴板操作、轻提示消失、外部修改冲突保护、草稿保留和关闭行为。
- 编辑中来回切换语言：文本控件实例、草稿和选区均不变。
- `SWB_QA_SCREEN=language-settings`：观察通知、偏好保存、中文/英文立即切换、已连接终端状态翻译；终端实例和连接标识不变。
- 时钟验证：24 小时制、前导零、跨日、非整点时区和固定行高。
- 核心回归与独立英文运行检查通过。中英文 README 和使用说明同步更新。

原始日志和截图位于忽略目录 `.test/`，不公开主机、用户目录或剪贴板内容。后续回归应继续检查真实保存链路和视图身份，不能只检查翻译字典或按钮标签。

测试窗口未获得前台焦点时，全局投递的快捷键不会到达编辑器。验收改为向测试窗口定向发送原生按键/鼠标事件，避免依赖抢占用户的当前窗口；不直接调用保存函数代替交互。

## 安装验证边界

Apple Silicon 和 Intel Release 编译通过，通用应用静态签名检查通过。但本次通用版与 Apple Silicon 版试启动均被系统以 SIGKILL 终止，尚未进入功能验收；系统日志出现 ad-hoc 签名相关记录，本机无有效代码签名身份。现有证据不能唯一判断终止来自哪项系统或组织策略。

没有关闭系统防护、移除策略或改名规避限制；未用新包覆盖正在运行的旧应用，也未发布 GitHub Release。功能结果来自 Debug 原生界面、本机和隔离 SSH 回归，不能等同于本次 Release 已完成安装验收。后续需核对用户正常打开应用时的系统提示，并按合法签名或管理员授权流程处理。
