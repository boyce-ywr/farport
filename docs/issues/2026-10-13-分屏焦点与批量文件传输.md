# 分屏焦点、点击区域与批量文件传输

- 日期：2026-10-13。
- 版本：0.1.1。
- 严重程度：中，影响交互与完整文件工作流。
- 修复 commit：见本文件 Git 历史。

## 分屏与标签

原实现将当前选中的终端 ID 同时当作左窗格 ID，点击右侧终端标签还会直接清空分屏 ID。因此标签切换与布局互相覆盖。

新增独立的 `TerminalLayout`：左右窗格与焦点分别保存。点击已可见的终端只切换焦点；选择其他终端时替换焦点窗格，不拆除另外一侧。只有明确结束分屏或关闭窗格才改变布局。工作区标签的完整矩形区域都参与点击；终端标签按钮和关闭按钮分开，且各自保留足够大的点击区域。

核心断言验证布局状态；`scripts/check-tab-interactions.sh` 向真实原生窗口投递鼠标事件，验证左右标签、标签留白与切换工作区。测试坐标计算包含 macOS 标题栏 safe-area，避免点到另一块内容而产生假失败。

## 批量文件工作流

统一 `FileClient` 文件浏览接口，分别由本机文件系统和 SFTP 实现。文件工作区新增“此 Mac”入口，不需要先保存 SSH 主机。当前主机与所有 SSH 主机都是可选源和目标，同主机不同目录也可以复制。

表格使用多选集合：⌘ / ⇧ 选择、⌘A 全选、⌘C 在应用内复制、切换目的目录后 ⌘V 粘贴。键盘拦截只在文件表格获得焦点时生效，不影响终端、文本编辑器或路径输入框的复制粘贴。

每个顶层选中项生成独立传输任务，文件夹递归复制并保留空目录。批次预检去重，阻止同目录、复制到自身子目录及多个来源的同名目标冲突。默认不覆盖已有目标文件；部分条目失败不会伪装成整个批次成功。

## 验证

隔离集成环境遍历本机、SSH A、SSH B 的 3×3 源/目标矩阵。每个方向一次选择普通文件和嵌套目录，检查文件内容及空目录保留，不仅验证任务状态。

`scripts/check-batch-copy.sh` 在真实文件表格上验证目录双击、键盘多选、复制以及粘贴生成的真实传输任务。
