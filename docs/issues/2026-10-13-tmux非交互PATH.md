# tmux 非交互 PATH 导致会话管理误报

- 日期：2026-10-13；版本：0.1.4；严重程度：中。
- 修复提交：见本文件首次引入的 Git 提交。
- 影响：交互终端能使用 tmux，但管理列表或附着提示找不到命令。

根因是交互 Shell 与 SSH 管理命令使用不同 PATH。不能把命令不可用当成没有会话，也不能通过加载任意 Shell 初始化文件解决，避免副作用及协议输出污染。

`RemoteTmuxCommand` 在对端验证 `command -v tmux` 的绝对可执行路径，并回退检查 Homebrew、MacPorts 和常用系统目录。管理和附着共用同一个解析器；不修改用户配置。

`scripts/check-tmux-path.sh` 在独立测试容器移置 tmux 到普通 PATH 以外，确认裸命令失败，随后验证会话创建、枚举、重命名、窗口/分栏及真实 PTY 附着/分离。只处理带测试身份的容器，不移动真实主机的 tmux。
