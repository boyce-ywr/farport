# 目录历史、多语言与文件预览

- 日期：2026-10-15；版本：0.1.7；修复提交：见本文件首次引入的 Git 历史。
- 范围：文件导航、应用语言、媒体预览和源码高亮。

## 目录返回

父目录不等于上一次访问位置。每个 `FileModel` 独立维护最多 100 条成功访问历史；刷新同一路径不压栈，失败或取消请求不修改历史。返回目标先尝试加载，成功后才弹出历史。切换来源保留各自状态，不影响终端布局。

导航开始时取消旧预览，预览错误按世代绑定，避免上一文件的迟到错误覆盖当前内容。已有操作汇总仍优先于后台预览错误。

## 语言

新增简体中文、英文和跟随系统选项。语言在下次启动生效，不为了切换界面重建终端或停止传输。

文案使用显式 `L10n.text` 调用；中文作为稳定的源文案，英文资源随核心资源 bundle 打包。插值参数在翻译之后单次替换，文件名、主机名、路径、终端内容与协议参数不做自动翻译。原始枚举标识及保存格式保持不变。约六百条资源覆盖菜单、设置、操作确认、状态和应用自己的错误提示；远端命令/系统原始错误不强制翻译。

认证助手通过连接进程传入的语言选择使用同一资源。单独启动 helper 与 app bundle 的资源目录不同，因此同时检查应用 Resources 与 helper 相邻的 `../Resources`。本机 Shell 不继承内部语言控制变量，不改动其 LANG 或用户配置。

## 音视频

复用只监听 127.0.0.1 的随机令牌 HTTP 服务。媒体模式只开放选中的一个文件，不开放同目录其他文件；保持路径、Host、Origin、符号链接检查和 GET/HEAD/Range 支持。媒体单文件上限 32 GiB，按 1 MiB 块读取，不在开始播放前整文件下载。

AVPlayerView 提供播放、暂停、音量与进度跳转。默认不自动播放；切换文件/来源或关闭预览时释放播放器并撤销媒体服务。支持取决于 macOS 原生解码能力；MP4 扩展名不代表其内部所有编码都受支持，MKV/OGG 等不承诺可播放。未引入 FFmpeg 转码或远端运行程序。

## 高亮

只读预览支持 JSON/JSONC、XML/SVG/plist/XHTML、Java、Python、JS/TS、Shell、Go、Rust、C/C++、Swift、SQL、YAML、TOML。使用 UTF-16 范围的词法扫描，区分关键字、函数调用、字符串、数值、字面量和注释；保留原文，不解析或执行脚本、不展开 XML 实体。

这不是编译器或 LSP：嵌入语言、模板内表达式、语言方言和从文件中段开始的预览只提供尽力而为的颜色提示。文本依旧按现有 512 KiB 分页，不自动格式化或改写源文件。

## 验证

- 历史单元测试：首项、刷新、分支跳转、连续返回、容量上限；真实 UI 验证返回按钮、失败/取消导航与来源隔离。
- 本机 HTTP 测试：Range、HEAD、错误令牌、单文件目录隔离、超过 256 MiB 的稀疏媒体头部请求。
- 隔离 SSH 上实际生成并读取 WAV 与 H.264 MP4；AVPlayer 加载、播放、暂停、1.5 秒 seek，通过视频输出检查真实 640×360 非黑解码帧。播放测试静音，未访问用户媒体。
- JSON/XML/Java/Python 真实远端预览验证 NSTextView 保留原文、颜色多样性；其余语言补充扩展名、注释/字符串隔离、Unicode、残缺输入、大文本与 token 边界测试。
- 语言资源逐项检查占位符一致性，中文与英文运行时分别验证；中英文设置和文件界面截图已查看。用户主机名及文件中中文保持原样。
- 所有测试内容、媒体、截图和临时令牌留在 `.test/`，不提交私人数据。Intel 构建不等于真机运行，原生媒体不代表所有格式兼容。
