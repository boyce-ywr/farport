# 传输冲突与工作台预览

- 日期：2026-10-14；版本：0.1.5；严重程度：中（交互缺陷及预览访问边界）。
- 修复提交：见本文件首次引入的 Git 历史。
- 范围：本机/SSH 传输、标签管理、主机编辑器和文件预览。

## 现象与定位

1. 传输引擎遇到同名目标直接抛普通异常，UI 只有失败和重试，不能在原任务批准覆盖。最小本机文件测试要求“等待确认”，旧版稳定失败。
2. 清理只识别 completed，failed/cancelled 长期留在队列。
3. 标签缺少排序接口和溢出管理，标签多时难以定位。布局模型不能因排序重建会话或改变分栏归属。
4. 主机弹窗在自动标签布局的 Form 中嵌入多字段 HStack 和单行颜色选择，固有宽度超过 560 点；外层宽度约束不会压缩内部所有内容。
5. 文件预览宽度限制为 480 点；HTML 只能看到源码、PDF 没有独立渲染。Haven 的 SFTP 回环服务仅作为协议思路参考，未复制其 Android 实现。

## 修复

- 引入可持久化的 awaitingConfirmation 状态和冲突快照。在写入前汇总目录/同名文件冲突，不兼容路径不再向下遍历。原任务批准后恢复；同名目录合并、额外文件保留，类型冲突和符号链接不能被批准覆盖。
- 覆盖授权只针对用户看到的路径和属性快照，不是自动允许后来出现的全部冲突。发布前再次检查；快照变化则重新确认。SFTP 没有跨客户端原子比较交换：同大小/同时间/同权限的外部修改或最后 rename 瞬间的竞争不在保证范围内，不宣称提供分布式锁。
- 清理仅作用于已结束且工作线程已退出的记录，不删源文件、目标文件或 `.part`，保留进行中、暂停及待确认任务。
- Tab 排序只移动组，使用窗口专属标识验证拖放载荷；横向滚动与可搜索的全部标签列表处理溢出。
- 主机表单改为独立分区、标签在输入框上方、固定内边距、用户名/端口明确配比，颜色网格自动换行。小屏内容可滚动，底部动作固定。
- 预览分隔条扩大命中范围并保存当前来源宽度比例；PDFKit 处理完整 PDF，提供翻页、缩放；HTML 通过本机随机端口/令牌访问当前报告目录。

## HTTP 预览边界

- 只绑定 127.0.0.1，每次服务生成 256-bit 随机令牌；GET/HEAD、单范围 Range，最多四个并发连接，有限头部、读取块及超时。单资源上限 256 MiB，PDF 内嵌上限 32 MiB。
- 每个服务固定主机快照及 HTML 所在目录；拒绝文件系统根目录、目录穿越、编码穿越、符号链接、非普通文件、错误令牌、非回环 Host、外站 Origin/Sec-Fetch-Site；不返回目录列表或写接口，不启用 CORS。
- 本机使用真实 canonical path 和 openat/O_NOFOLLOW 逐级打开相对资源。macOS 的 `/var` 是系统链接，Foundation 的路径标准化没有完全消除它；改用 POSIX realpath 后再执行安全校验，避免错误阻止所有临时目录。
- 远端使用 SFTP 检查路径并打开独立文件句柄，避免每个读取块重复打开文件。SFTP 不提供跨客户端无竞争的逐级 openat；不保证抵御远端自身在检查/打开间恶意替换路径。远端 SSH 主机仍是受信任端点。
- 默认 CSP 禁止脚本与外部资源；用户明确选择可信报告后允许本目录脚本及同源数据，仍限制外部网络和表单。内嵌 WKWebView 拒绝外部导航；系统浏览器的用户主动操作按浏览器规则处理。
- URL 是临时访问能力，不应分享或上传日志。停止服务/退出应用撤销；最多保留八个服务。HTML 的父目录之外资源、绝对根路径资源、外部 CDN、服务器端 API 不是完整网站部署，不自动代理。

## 验证

- 核心测试覆盖冲突前保留原文件、批准覆盖、快照变更、目录合并、类型不兼容、符号链接、状态持久化与可清理状态，以及标签排序不改变焦点/分栏。
- 真实 HTTP 测试覆盖 HTML、相对 CSS、查询/锚点、HEAD/Range、错误范围和上述授权边界。
- 隔离 SSH 的 HTML/CSS 经真实代理返回；WKWebView 加载标题。Ego 浏览器在同一临时 URL 上验证 CSS 生效、锚点跳转、默认脚本不执行、可信模式脚本执行。
- 原生图形验证覆盖主机测试连接成功、深浅色留白、十二个标签排序、多分栏保持、冲突恢复、记录清理、PDFKit 及预览分隔条真实拖动。
- 原有分栏测试的直接 `mouseDown` 调用绕过 NSWindow 的 first responder 更新，导致误报；改为系统事件队列派发，不改生产焦点行为。后台无活动窗口仍明确 SKIP 物理事件验收。
- 截图、临时 URL、测试密钥及远端测试路径只保存在 `.test/`，不上传仓库。
