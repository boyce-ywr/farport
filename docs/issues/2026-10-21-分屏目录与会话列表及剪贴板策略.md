# 分屏目录、会话列表和剪贴板策略收尾

- 日期：2026-10-21；影响版本：0.1.14 开发预览构建 19；本轮修复进入构建 20。
- 严重程度：中；目录继承和列表授权阻碍日常使用，剪贴板请求反复询问影响 tmux 复制体验。
- 修复提交：与本文一起提交，`git log -1 -- Sources/OpenSSHBackend/LocalProcessDirectory.swift` 可定位。不覆盖正式 0.1.13 发行包。

## 一、分屏没有继承当前目录

用户源窗格在 `~/Projects`，新分屏却落在主目录。真实 PTY 回归复现：源进程 `cd` 到带中文/空格/引号的项目目录后停在输入接收器；`newTerminal(split:true)` 创建的新 Shell 实际 `/bin/pwd -P` 仍为主目录，失败信息已保留。

原分屏调用与普通新标签共用 `LocalShellConfiguration` 的固定 home，没有源目录参数。修复后绑定发起分屏的 TerminalSession/connectionID：本机读取原前台进程内核 cwd；tmux 从原 pane 查询；普通远端只接纳已有可信目录报告。读取完成后若原连接已变化，不使用其目录。新进程显式设置 cwd/PWD，但 HOME 不变；不向原终端注入 `cd`，不全局 chdir。源为 Docker、二次 SSH 或无法确认的用户时不把内部路径传给宿主。

验证：中英文左右/上下分屏、启动期间切换焦点、原 PTY 零输入、独立新标签仍为 home、缺失/非法路径回退、本机及两个隔离 SSH tmux 来源目录通过。命令：`bash scripts/check-split-directory.sh --ssh`。内部分割 tmux 不在本次更改范围，已有 tmux split 行为保持。

## 二、会话历史开关选不上及空列表

源码中开关开启会同步调用 `NSAlert.runModal()`，只要返回值不是首按钮就写回 `history=false`；该状态变动又触发刷新。用户观测到点击后短暂加载、恢复未勾选，与这条路径一致，但没有把某次 UI 的具体返回原因虚构为已复现。

依据用户明确要求，移除开关和二次确认，而不是仅默认勾选；打开面板或切 Agent 即自动扫描其所有项目。启动目录收进折叠区，不再筛选/优先排序历史。读取失败、未取到列表、无匹配、存储目录不存在各有提示。工具切换使用请求代次和取消保护，旧结果不覆盖新工具。

扫描器不再只看前 1/8 行，也不固定截断 200 条：流式解析会话事件，Claude 提取显式名称/摘要、Codex 名称索引、Pi session_info，显示完整 ID、工作路径和最后事件时间。没有名称显示未命名；缺事件时间才降级到索引/文件时间，文件估计显式标识。Codex 已知 JSONL 归档也覆盖，未知压缩格式给提示。扫描有 60 秒、2 MiB 单行、12 MiB 输出限制，超限表示不完整而不是假装全部读取。

测试：九个 Python 回归覆盖三个 Agent、不同项目、名称更新、实际活跃时间与 mtime 相反、240 条完整返回、归档恢复、目录不存在、异常格式、文件不被改写。中英文 App 模型夹具实际显示三行有名称/完整ID/路径/活跃时间，修改启动目录不改变列表。真实构建机只输出计数的只读验证读到 62 个去重 Codex 会话和 3 个 Pi 会话；该用户 Claude 数据根不存在，明确 root-missing。上述数量不是用户另一设备/容器的会话数量；未把用户正文或会话标题落到报告。

## 三、终端剪贴板配置

按用户要求新增持久写入策略：每次连接首次询问（默认）、始终允许写入、不允许写入；另有默认关闭的“允许当前终端读取 Mac 文本剪贴板”。选择始终写入后跨连接不弹确认；读取开关内联展示密码等敏感文本可能被当前终端读取的风险，不再通过另一层弹窗阻断设置。

前后台/焦点/弹窗检查、写入回读、UTF-8/1 MiB 上限保留；读取仅文本且限频。单终端禁止仍生效，全局禁止不能被单终端允许绕过；显式选区复制不变。SwiftTerm OSC52 解析器的真实输入测试验证读写、禁用即时生效、持久化、重连和后台保护，不只检查设置变量。
