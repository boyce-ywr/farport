## 路径解码必须先校验完整内容

最小回归输入：`file://dev.example/tmp/%00`。初稿使用 `URLComponents.path` 再检查控制字符，回归测试发现没有拒绝这个输入。

修复：从 `percentEncodedPath` 显式执行一次完整百分号解码，再检查绝对路径、长度、控制字符及主机身份。解码失败同样拒绝；不二次解码合法的字面百分号。测试覆盖 `%00`、编码换行、外部主机、凭据、查询参数及无来源的裸路径。

相关文件：`Sources/WorkbenchCore/WorkspaceTools.swift`、`Tests/WorkbenchCoreTests/WorkspaceToolsChecks.swift`。

## 命令插入与剪贴板粘贴不是一个 API

SwiftTerm 的 macOS `paste(_ sender: Any)` 是菜单动作，会读取剪贴板，不是接收文本的插入方法。将命令字符串作为 sender 传入并不能插入那条命令。

实现改用已有的文字发送路径，并明确不追加回车。片段拒绝换行及控制序列；插入前复核终端标识、连接代次、适用主机和备用屏幕状态。原生 PTY 测试用实际文件副作用验证：插入后文件不存在，自行发送回车后才出现指定内容；同时验证剪贴板不变、切换终端后拒绝旧目标、全屏程序中拒绝插入。

## 恢复不能重放，也不能覆盖另一个窗口

记录布局与主机连接身份，只有空窗口可恢复。配置变化或主机已删除时跳过；明确的 tmux 标识原样附着，不用新会话冒充恢复。恢复出的每个窗口保留自身记录 ID，避免两个窗口覆盖同一个快照。布局恢复与远端进程保活分别描述。

工具 JSON 读取失败时禁用写回，避免异常退出或普通保存把原文件覆盖为空记录。手动保存命令须落盘成功后才显示成功。

## 桌面通道不使用信号量维持生命期

本机监听由 Network.framework 原子分配 loopback 端口；每个客户端使用独立 OpenSSH stdio 转发。管道复制的描述符设置 close-on-exec，DispatchIO 的关闭回调负责最终释放；读写分块并等待发送完成，防止慢客户端导致输出无限排队。停止请求在自己的串行队列完成资源关闭与终止信号发送，不在应用退出时只留下尚未执行的异步清理。

回归覆盖二进制往返、半关闭、反复启动/停止、真实隔离 SSH 认证后的目标端口访问和子进程退出。这些测试不能代替 Apple 系统账户的真实屏幕共享认证，产品入口因此保持实验标识。

## 原生 UI 验收的退出与截图

测试一度完成截图后进程仍留在事件循环。采样没有显示死锁；等待最后一个模态面板完成关闭后再请求退出，中文和英文两轮都正常结束。此修正在测试流程中，不通过强制结束进程冒充应用正常退出。

AppKit 的缓存截图带透明背景，直接查看可能只看到输入框；验收截图显式合成窗口背景后再保存，并查看实际布局。截图生成成功本身不是功能验收成功。
