# SFTP 异常文件名与原生交互

- 日期：2026-10-14；版本：0.1.5；严重程度：中；修复提交见本文件首次引入的 Git 历史。

## Termux 目录整体不可见

用户反馈一台 Termux/OpenSSH 设备文件页显示“文件名不是有效 UTF-8”。诊断仅使用用户指定设备的只读 SSH/SFTP 请求，主机指纹采用已有 known_hosts，未跳过校验，未重命名或删除远端文件。

原始 SFTP v3 回包确认：REALPATH 是正常 UTF-8，READDIR 共 257 条（含 `.`、`..`），其中 1 个 filename 为 12 字节、包含非法 UTF-8 和控制字节，对应 longname 也不是 UTF-8。旧客户端严格解码每条 filename 和仅用于展示的 longname，任一异常都会中止整页。

修复把目录条目字段按长度完整读取；longname 不用于路径，不强制解码。浏览模式跳过非 UTF-8/含控制字符的名字并显示数量，不使用 replacement character 猜测真实路径。正常路径仍使用严格 UTF-8，截断包和超限包仍报错。传输/递归删除用严格列表，异常名字不能被悄悄遗漏。

真实设备修复后返回 254 个可识别条目、1 个跳过提示；只读验证同时确认严格递归接口拒绝静默跳过。自动化回包测试验证坏条目之后的正常中文名字仍能解析，longname 的异常不会影响合法名字。地址、用户名、原始文件名及访问配置只保存在本机忽略的诊断目录，不写入公开文档或源码。

## 文件列三态排序

使用 Foundation 的确定性比较器处理自然名称、类型标签、真实字节大小、时间戳和权限，保留目录优先与同值稳定后备顺序。SwiftUI Table 默认排序交互只有双向且会回写内部状态，不能用任意 binding setter 回调计数表达第三态。

改为对本表头命中区域处理原生点击，每次点击只推进一次显式三态；保留系统列边缘的缩放操作，Table 只负责显示箭头。真实表头 15 次点击验证五列的升/降/默认、文件选择不变及来源切换保留。

## 顶部双击

隐藏标题的 SwiftUI 窗口使用窄范围 AppKit 事件处理，双击当前窗口顶部空白区域按当前屏幕 visibleFrame 填满并保存还原 frame；排除红黄绿按钮、正文、sheet 和系统全屏。退出视图即移除事件监听。

原生事件测试验证两轮最大化/恢复、位置与尺寸、非全屏、不改变终端会话，以及正文/系统按钮不触发。多显示器和实体鼠标的长期使用仍需人工覆盖。
