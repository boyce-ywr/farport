# 终端离屏截图透明层

- 日期：2026-10-13。
- 影响：无屏幕录制权限时，应用自身的离屏窗口截图。
- 严重程度：视觉验收误报；SSH 内容没有损坏。
- 修复 commit：未提交。

## 现象与定位

初始截图中，终端背景是黑色，文字出现毛边，但其他界面清晰。原生视图记录的背景颜色、字体、字号以及 SSH 连接状态均正确。读取 SwiftTerm 的实际绘制代码发现：默认背景依赖 CALayer，CoreGraphics 绘制会先清除区域至透明；`cacheDisplay` 的离屏图像没有自动合成这层背景。

直接重新渲染 layer 未解决。也确认不能从本项目覆盖第三方模块中未开放的 `draw` 方法，因此未修改依赖源码或使用方法替换。

## 修复

离屏截图完成后，仅在真实可见终端区域以 `destinationOver` 合成该终端实际的 `nativeBackgroundColor`。不重绘、替换或伪造终端文字。系统有屏幕录制权限时仍优先使用系统窗口截图。

## 验证

打包程序真实建立 SSH 连接并打印远端输出，修复后的图像中文字清晰、背景与实际视图属性一致。截图旁的 JSON 记录采集方式和应用身份，明确区分 WindowServer 截图与应用视图离屏快照。后者不能替代显示器缩放、输入法和全部鼠标交互的人工验收。
