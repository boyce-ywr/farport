# 功能与使用细节

安装及快速上手见 [首页](../README.md)。这里保留较完整的操作说明和边界。

## 主要能力

### 主机监控与终端偏好

- “监控”（`⌘6`）可选择本机或已配置 SSH 主机，查看概览、可见进程、网卡上下行、TCP 监听/UDP 绑定端口及系统/当前用户信息。默认两秒刷新，可暂停；离开页面停止采集，最近十五分钟 CPU/内存曲线仅保存在当前页面连接的内存中。
- 磁盘使用紧凑表格对齐挂载点、已用/总量、可用空间与使用率；系统信息按操作系统、硬件、当前用户分组，长路径和用户组仍可查看及复制。
- 进程表六个表头均可点击循环“升序 → 降序 → 默认”；数字按原始 CPU/内存字节/运行秒数排序，不按显示文本。缺失值始终在末尾，同值按 PID 升序保持稳定；默认恢复 CPU 降序。刷新、暂停和搜索不重置排序选择。
- Linux/macOS 已实测。Windows 提供 PowerShell/CIM 适配，但尚未 Windows 真机验收；Termux 按 Android 权限降级，本轮设备不可达，未完成监控实机验证。不可用指标显示 —；进程级带宽不提供，端口 PID 仅在工具和权限允许时显示。
- 监控只读，不安装采集组件，不自动提权，不结束进程、不重启服务，也不后台告警。进程 CPU 以单核 100% 为基准，RSS/Working Set 不能直接当作独占内存；网卡可能含虚拟接口，不简单相加。
- 终端默认右键提供复制、粘贴、全选、清除选择。设置中可对应用附着的 tmux 改用原生 tmux 菜单；使用 `M-MouseDown3Pane` 对应的 Meta＋右键事件，避免被开启鼠标模式的前台程序接走。`Shift＋右键` 临时回到普通菜单，不修改远端按键绑定；自定义 tmux 配置仍以远端绑定为准。启用 tmux mouse 只修改选定会话，但共享该会话的其他客户端也会受到影响，操作前会确认。
- 附件自动插入由全局默认（开启）和主机级覆盖共同决定；本机继承全局。新上传捕获设置；开始时为手动模式的任务不会因后来开启设置而自动发送，进行中关闭自动插入则停止自动发送。换终端、连接、输入位置或 tmux 目标时仍停止自动插入；不自动回车。手动模式只上传校验，等待“插入原终端”。
- ⌘V、右键粘贴及拖入的图片/文件共用自动插入策略。光标位置/设备查询等终端协议自动回包不算用户输入；真实打字、鼠标操作目标、切换标签/窗口、连接变化及后台状态仍受保护。
- 开发版会在上传和文件复核后短暂等待原终端焦点稳定，不再因一次瞬时失焦立即要求手动插入。不会从其他输入框抢焦点，不在后台或模态窗口中发送；等待超时会解释原因。中英文本机、隔离 SSH 及 tmux 的原生前台回归已通过，安装包交付仍单独验收，详见 `issues/2026-10-19-附件自动插入焦点竞态.md`。

### 语言与文件导航

- 设置 → 语言可选择简体中文、English、跟随系统，选择后立即切换并自动保存，无需重启。应用导航、菜单、文件、监控、传输和设置界面跟随切换；不会断开 SSH、重启传输或丢失编辑草稿。终端输出、用户文件和主机名称保持原样，已有历史消息不重新翻译；系统对话框遵循 macOS 语言。
- 文件工具栏最左侧“返回”回到上一次成功访问的路径，与“上一级目录”不同。每个来源独立保留最近 100 次历史；刷新、失败和取消不产生新历史。
- 音视频按需读取并用原生播放器预览，支持播放/暂停、音量与 seek。只开放当前文件，不公开同目录其他内容；切换来源或关闭预览撤销服务。媒体上限 32 GiB，实际支持取决于 macOS 编码器，WAV/H.264 MP4 已实测。
- JSON/XML、Java、Python、JS/TS、Shell、Go、Rust、C/C++、Swift、SQL、YAML、TOML 只读高亮，不自动格式化或执行代码。保留原有文本分页，复杂语法和文件中段不保证完整高亮。

### SSH 与终端

- 左侧“本机终端”直接打开当前 macOS 用户的登录 Shell，从用户主目录开始，无需配置主机或启用系统远程登录；不会连接 `localhost`。
- 本机和 SSH 共用终端、标签、分屏、搜索、字体、深浅色及粘贴保护。支持本机↔本机、本机↔SSH 混合分屏，标题明确标注 `LOCAL` / `SSH`。
- 本机终端读取系统账户配置的 Shell（本机为 zsh），继承正常环境并执行该 Shell 原有启动配置；不修改配置文件、不安装插件、不更改默认 Shell。
- Shell `exit` 后保留标签并显示“已结束”，可“重新打开”；关闭或重开正在运行的本机 Shell 会确认。它不是后台持久会话，任务可能随 Shell 结束，需保留的工作可在终端自行使用 tmux。
- 系统 OpenSSH 负责密钥、SSH Agent、密码/私钥口令、交互式认证、主机指纹验证与 ProxyJump。
- 首次连接通过原生提示核对指纹；变化的指纹不会自动接受。
- 主机分组、搜索、按需导入可信 SSH 配置；支持逗号分隔的多级跳板机。
- 主机弹窗支持测试当前未保存配置：分别验证 SSH 认证与 SFTP 访问，支持取消，编辑参数后清除旧结果。
- SwiftTerm 原生终端，多标签、多窗口、左右/上下嵌套分栏、滚动历史、内容搜索、中文/Unicode、字体字号设置；触控板双指捏合可缩放字号（10–28）。
- 一个标签管理一组分栏。新建终端打开独立标签，分栏只拆分当前标签的焦点终端；切换标签保留各组比例、焦点和连接。标签显示分栏数量，各分栏标题显示来源、焦点和文件入口；最大化可还原，不关闭其他分栏。
- 标签支持拖动排序、右键移到最前/最后；数量较多时可横向滚动，或打开右侧数量按钮搜索、切换和关闭标签。排序不改变分栏或终端身份。
- 终端组和文件来源标签分别排序；文件页拖动一个分栏的文件来源不会移动整组终端。单窗口顺序保留，不承诺跨启动会话恢复。
- 顶部导航合并为紧凑工具栏；侧栏可用按钮或 `⌘⌥S` 折叠，搜索按需通过 `⌘F` 展开，附件成功提示压成单行，为终端保留更多面积。
- 配置主机使用分区表单、独立字段标签、统一内边距和可换行颜色网格；小屏滚动表单，底部测试/保存按钮保留。
- 顶部空白标题栏双击填满当前屏幕可用区域（保留菜单栏与 Dock），再次双击恢复原大小和位置，不进入独立全屏空间。
- 主机标记提供十种颜色，保留旧颜色配置；终端标签与主机颜色一致。
- 会话断开后可点击重连。普通 SSH 的前台进程不保证继续；需要持久任务时使用 tmux。
- 本地转发、远程转发、SOCKS5；默认请求绑定回环地址。远程监听最终还受服务器策略控制。

### tmux

- 本机和 SSH 使用同一套 tmux 管理界面。本机使用当前用户已有的 tmux；不会更改全局 tmux 配置。附着后关闭标签只分离，不结束会话。
- 本机目录修复（尚未包含在已发布的 0.1.12）：新建 tmux 会话从用户主目录启动；在已有会话中新建窗口或分割窗格时，继承目标窗格目录，而不是 Farport 的启动目录。重新附着旧会话不改变其当前目录；旧窗格若已在 `/`，可自行执行 `cd "$HOME"`，无需结束会话或重启 tmux 服务。
- 读取远端会话、窗口与窗格状态；创建/重命名/结束会话、新建窗口、分割窗格、进入指定窗格。
- 按主机记住最近的会话；启用 tmux 优先后，已存在的最近会话可再次进入。
- 关闭终端与结束会话分开处理，结束远端会话必须确认。
- 没有安装 tmux 时显示原因，仍可打开普通 SSH；不会自动安装软件。
- 远端 tmux 管理与附着共用可执行文件探测，兼容非交互 SSH 的 PATH 缺少 Homebrew 等安装目录；不修改远端 Shell 配置。

### 远程文件

- 文件页支持独立分栏：`⌘D` 左右分栏、`⌘⇧D` 上下分栏，最多 8 栏；也可使用每栏右上角的分栏菜单。拖动分隔线调整宽度，`⌘⇧Return` 最大化/还原当前栏，`⌘[` / `⌘]` 切换活动栏。
- 每栏顶部独立选择“此 Mac”、SSH 主机或已有终端的文件来源；目录、筛选、选中项、排序互不干扰。同一主机也可以在不同栏打开不同目录。分栏布局不跨重启保存。
- 在源文件列表多选后按 `⌘C`，点击目标栏列表或切换该栏主机，再按 `⌘V`，复制到目标栏当前目录；支持本机、SSH 主机和同一 Farport 进程的不同窗口。路径框和筛选框内仍是普通文本复制粘贴，不会触发文件传输。
- 可以拖动选中的文件行到另一文件栏，效果也是复制到目标栏当前目录（不是拖到哪一行就进入那一行的子目录），不会移动或删除源文件。支持多选、目录和从 Finder 拖入/复制文件；文件栏私有引用不支持跨 Farport 进程、重启后粘贴或直接拖出到 Finder。
- 拖拽和快捷键复用传输队列；同名目标仍先确认覆盖，同目录自复制或复制目录到自身子目录会拒绝。源/目标主机配置失效或拖入期间目标栏、目录变化时不开始复制。传输提示表示“已入队”，最终结果在传输队列查看。
- 多栏默认收起新文件来源的预览，可点路径栏的预览按钮恢复；不会为了显示预览而挤掉另一文件栏。

- 终端和文件页共用会话标签，同主机多个终端以序号区分。文件路径上方明确显示来源，支持直接切换已打开的会话、此 Mac 或任意已保存主机，并一键回到对应终端。
- 每个会话独立保留目录、筛选和选择；浏览其他来源不改动终端分屏。缓存仅在本窗口会话生命周期内保留，不等于自动跟踪 Shell 中的每次 `cd`。
- 原生表格、绝对路径导航、主目录、目录过滤、隐藏文件、权限与修改时间。
- 单击目录名称或目录行仅选中并预览，双击才进入子目录；原生行激活不依赖可能滞后的选择状态。
- 左侧“此 Mac 的文件”可浏览本地目录；本机与各 SSH 主机均可作为源或目标，同一主机的不同目录也支持复制。
- 支持 ⌘ / ⇧ 多选、⌘A 全选、⌘C 应用内复制、切换主机/目录后 ⌘V 批量粘贴；“传输到…”支持批量文件及文件夹。
- 文本分段预览（每页 512 KiB）、图片预览（文件最大 8 MiB）、日志末尾每两秒刷新。
- 小型 UTF-8 文本编辑；保存前核对元数据与原始内容，写入临时文件后原子替换。
- 创建、重命名、修改权限、删除、上传、下载；支持拖入本地文件上传。
- 删除不经过废纸篓，危险操作会确认。
- 预览区支持左右拖动分隔条改变宽度，双击恢复默认。支持文本、图片、HTML 页面/源码、PDF 原生翻页与缩放（内嵌 PDF 上限 32 MiB）。
- Markdown 支持原生格式预览/源码切换，编辑器可并排实时预览；512 KiB 编辑上限，保存仍检查内容冲突。不会执行嵌入 HTML 或自动请求图片资源。
- 编辑器提供保存、撤销、重做、剪切、复制、粘贴和全选按钮。`⌘S` 保存后不关闭窗口，“已保存”轻提示约两秒后消失；写入期间暂时锁定输入，完成后继续编辑。每次成功保存都会更新冲突检查基准，撤销历史保留；保存失败不丢弃草稿，关闭时对未保存修改确认。
- 目录符号链接可单击查看目标类型、双击进入真实目录；普通文件链接允许只读预览，不通过链接编辑。递归传输与删除不自动跟随链接，网页代理仍保持目录隔离规则。
- 文件列表新增文件类型列；名称、类型、大小、修改时间、权限五列均可点击循环“升序 → 降序 → 默认”，方向箭头和底部排序说明同步显示。文件夹始终优先，名称自然排序；类型按扩展名识别，不扫描文件内容。各文件来源独立保留排序状态。
- 遇到非 UTF-8 或含控制字符的 SFTP 文件名，文件浏览显示正常条目并明确告知跳过数量，不生成可能误操作的替代路径；目录递归传输/删除仍严格拒绝忽略这些条目，请先在目标主机处理异常文件名。
- HTML 的“在浏览器打开”使用仅监听 `127.0.0.1` 的临时令牌 URL，通过 SSH/SFTP 按需读取当前报告目录的相对资源，不在远端启动服务。默认禁用脚本，可信报告可明确启用；不自动加载外部 CDN、代理后端 API 或越出当前目录。单资源上限 256 MiB，停止服务或退出应用会撤销链接，请勿分享令牌 URL。
- 右键多选文件/文件夹可批量删除；确认显示目标主机、目录、数量和文件名。失败项保留并报告，未选项目不受影响；右键未选中的项目只操作该项目。

### 传输

- 完成记录不再占用大进度卡片；详细源/目标路径按需展开。文件夹按钮在 Finder 中选中已下载的目标或已上传的本机源文件；远端互传没有本机入口。文件已移动或删除时会提示，不会打开无关路径。

- 本机↔远端、远端↔远端、目录递归复制，共用持久化队列，最多两路并行。
- 远端互传为 **Mac 流式中转**，不是两台服务器直接连接；不把整个远端文件落地缓存到 Mac。
- 按 64 KiB 请求流水化，单批最多 2 MiB，有界缓冲。
- 进度、速率、暂停、取消、失败重试；重启应用后将未完成任务标记为暂停。
- 恢复前逐字节核对已有部分，并检查源大小/修改时间，拒绝损坏断点。
- 部分文件带 `.swb-<任务 UUID>.part` 后缀，完成后再发布最终文件。默认拒绝覆盖。
- 不自动跟随符号链接，不复制设备、管道和套接字。新目录先以 700 创建，完成后恢复源目录的权限和修改时间；已有目录不会被改权。

### 终端图片与附件

- 在具体终端窗格中 `⌘V` 粘贴剪贴板图片，或粘贴 Finder 复制的文件、拖入文件/文件夹、使用“发送附件”按钮多选。所有入口走同一条目标绑定和校验流程；普通文本粘贴不受影响。
- 不再弹出上传目录确认窗口。剪贴板图片先编码为 PNG；远端附件通过 SSH/SFTP 上传到对端 `${TMPDIR:-/tmp}` 下独立的 `.farport-attachments-<UUID>` 私有子目录，本机使用系统临时目录。只有目标机器回读内容、验证 SHA-256 与权限通过后，才插入引用。进度、取消和重试以内联横条显示。
- 附件目录为 700，普通附件文件为 600。不会覆盖已有同名文件，也不会把 Mac 本地路径插入远端终端。文件夹支持递归上传与校验，符号链接/特殊文件拒绝。
- 插入的是经过引用的目标机器绝对路径，不是伪造图片标记；不自动按回车。图片是否显示为原生附件，由实际 Agent 识别。Codex CLI 0.162.1 在远端 tmux 内已实测将单张图片路径识别为 `[Image #1]`；远端模型也读出了图片中的随机数字。Claude Code 的真实模型会话尚未验证，不能据此声称全部 Agent/版本都通过。
- 任务绑定发起时的终端、连接、输入状态及窗口。状态变化时停止自动插入，保留已上传结果等待明确确认。通过应用附着的 tmux 会话进一步锁定 pane ID、进程、命令、目录和模式；切换窗格、复制模式或目标退出时拒绝发送，不擅自切窗格。
- 手动二次 SSH、容器、`su`/`sudo`、不同用户及 Agent 沙箱都可能改变可见文件系统。接收程序必须与上传连接共享机器/用户和目录；否则改用实际目标连接或合法共享路径。**不自动穿透这些环境**。在终端手工启动而非从应用附着的 tmux，无法可靠锁定 pane，请通过 tmux 管理页附着后使用。
- 附件不会随会话关闭删除，避免 Agent 稍后读取失败，但系统可能定期清理临时目录；长期使用请自行保存。上传横条可明确清理本批附件；也可在文件浏览器显示隐藏文件并删除专用目录。取消/失败可能保留该私有目录内的部分文件，不会发布路径引用。源文件不会被删除。

### 本机 tmux 中的 Docker 附件（0.1.13 预览）

- 从 Farport 的本机 tmux 管理页附着会话，在窗格里通过 `docker exec -it` 或可交互的 `docker attach` 进入容器。图片 `⌘V`、Finder 文件粘贴、文件拖入和发送附件入口复用同一流程。
- 首次发送会出现“选择目标容器”。列表标出“原窗格容器”，只允许确认与前台 Docker 进程一致的那个容器；同时显示 Docker 连接（context 或 Unix socket）、原窗格及接收用户。确认前不会向容器复制附件，也不能通过选择其他容器绕过目标核对。
- 文件通过 Docker 的 exec 标准输入复制，按已核对的 `docker exec --user` 或容器配置用户创建私有目录；不默认提权为 root，不改变容器挂载或要求重建容器。目标需具有 `sh`、`id`、`mktemp`、`mkdir`、`cat`、`chmod`、`sha256sum`、`rm` 等基础命令。
- 容器目录位于 `/tmp/.farport-attachments-*`，目录 700、文件 600；按目标用户检查目录清单、可读性和 SHA-256。校验后插入的是容器内路径，不是 Mac 路径，不自动回车。图片最终是否由 Agent 识别，以 Agent 自身结果为准。
- 同一 Farport 终端连接、tmux 窗格、Docker 前台进程、context/服务、容器启动状态和用户都未变化时，可在后续粘贴中复用已确认绑定。关闭或重连终端、退出重进容器、容器暂停/重启/重建、文件变化等会重新核对或阻止发送；绑定不跨应用重启保存。
- 构建 18 起兼容本机 context、`DOCKER_HOST=unix:///…` 和明确的 `docker -H/--host unix:///…`，连接选择由原 Docker CLI 的参数与环境决定，再固定到识别出的 Unix socket 和 daemon ID；不会静默回退到默认 context。TCP/SSH 等远程 Docker 地址、Docker Compose、Podman、二次 SSH、容器内再次切用户或进入另一容器仍不自动支持。容器内发生这些变化时必须取消发送，不能仅因外层仍显示 `docker` 就认为路径可读。
- 附件最多 100 个顶层项目、1000 个文件/目录条目、层级小于 64；单文件最多 128 MiB，每批最多 256 MiB。只读或精简容器、权限不足时明确失败，不自动安装命令、改权限或重新创建容器。
- 如默认 Docker context 配置在进入容器后已修改，需用明确 `--context` 重新连接。macOS 拒绝读取前台进程信息时保留安全拦截，按正常授权流程处理，不关闭防护。

## 终端复制与粘贴

- 本地选区可用 `⌘C`、右键“复制”或分栏顶部复制按钮写入 Mac 剪贴板。无本地选区时显示操作说明，不清空已有剪贴板。
- 在 tmux、Pi 等捕获鼠标的程序中，按住 **Shift 拖选**强制使用 Farport 本地选区；即使程序请求捕获 Shift 鼠标，仍保留这条本地通道。已存在本地选区时右键优先显示普通复制菜单。
- Farport 只有在写入并回读匹配后显示“已复制到 Mac 剪贴板”，提示覆盖显示，不推挤终端。
- 终端协议（OSC 52）写入 Mac 剪贴板需当前连接授权。首次请求会询问；拒绝后的请求不反复弹窗，但会明确提示已阻止，并暂存最近一条有效请求供用户补复制。分栏顶部或普通右键菜单可允许/禁止；重连时重置授权和待复制内容。
- 后台终端不自动覆盖剪贴板，用户可显式复制待处理内容。远端读取 Mac 剪贴板始终禁用；协议写入限有效 UTF-8、非空、1 MiB 以内。不要把终端程序自身的“Copied”提示当作 Mac 剪贴板回执。
- `⌘V`、右键和分栏粘贴按钮共用原有流程：普通文本直接输入，多行文本确认，图片/文件上传校验后按设置插入，不自动回车。

## Codex 宠物与终端图像

- 新建普通本地终端或 POSIX SSH 终端，运行 `codex`，用 `/pets` 选择、`/pets off` 关闭宠物。Codex CLI 0.163.0 的内置 Rocky 已在本机和隔离 Linux SSH 实测连续动画。
- Farport 提供 Kitty 内嵌图像与 Sixel 渲染。为兼容 Codex 当前按名称判断的检测，终端标识为 `TERM_PROGRAM=Farport-Kitty`；`TERM` 仍为 `xterm-256color`，不用给远端安装 terminfo。SSH 仅在当前会话导出标识，再进入原登录 Shell，不修改配置文件。
- 旧终端不会被自动断开或重启；升级后请新建终端。用户自定义 Shell 若覆盖终端标识，可在确认是 Farport 普通终端后用 `TERM_PROGRAM=Farport-Kitty codex` 启动。

- Kitty 图像仅接受内嵌数据，不允许经远端图像指令读取/删除 Mac 文件或共享内存；限制单图尺寸、传输长度和缓存。Codex 的自定义素材另有版本要求：0.163.0 的 CLI 使用 8×9 图集，桌面端的 8×11 素材不能直接视为兼容，不会自动改写用户素材。

## 数据与安全

- 默认数据目录：`~/Library/Application Support/SSH Workbench/`。
- 产品名为「栖远 Farport」。为保持已有配置、钥匙串与应用身份连续性，内部模块名、数据目录和 bundle identifier `local.sshworkbench.mac` 暂不更改；品牌命名不用于规避任何安全策略。
- 主机配置、传输清单、独立 `known_hosts` 保存在本机，目录权限 700，配置文件权限 600。
- 密码/口令只有在原生提示中明确勾选时才保存到 macOS 钥匙串，不出现在主机 JSON 中。
- 可以通过主机右键菜单清除此主机保存的凭据。
- 不扫描导入用户密钥，不创建云账号，不进行遥测。
- 拒绝远端 OSC 52 读取本机剪贴板；写入剪贴板要确认，多行粘贴要确认；外链仅接受 HTTP(S) 并确认。
- OpenSSH 配置可执行 `ProxyCommand`/`Match exec`，只应导入可信配置。自动导入只枚举所选文件里的具体 Host，不展开 Include 文件发现新主机；连接时 OpenSSH 仍解释完整配置。

## 明确边界

- 同名传输进入“等待覆盖确认”，在工作区横条查看冲突并选择覆盖/合并或取消。目录合并保留额外文件，不兼容类型与符号链接不可覆盖；目标属性发生变化会重新确认。传输界面也可提前明确允许覆盖。
- 传输中心支持清除失败/已取消记录、全部已结束记录和单条记录。清除不删除任何文件、不会清理 `.part`，进行中/暂停/待确认任务保留。

- 不包含 VNC、Android、Windows 客户端、云同步或完整远程 IDE。
- Mac 离线后不会替用户启动远端独立传输任务；恢复时需要重新连接并继续。
- 断点校验会重新读取已传输的前缀，会产生网络流量；这是避免盲目续传的取舍。
- 取消不会删除目标 `.part` 文件，任务详情会显示后缀；确认不再需要后可在远程文件浏览器中删除。
- SFTP v3 并不提供跨客户端的原子“比较并交换”。编辑器的双重内容检查降低覆盖风险，但不能对另一个客户端在最终重命名瞬间的写入提供锁保证。
- 文件传输保留基础权限和修改时间，不声称保留 ACL、扩展属性、硬链接、稀疏布局或所有权。
- UTF-8 文件名受支持；非 UTF-8 文本只读预览，不转换后静默写回。
- 编译出 Intel 产物不等于 Intel 真机验收；不能把本机 ARM 的结果冒充其他硬件或 macOS 14 的运行结果。
