# 工作工具二期与终端恢复

日期：2026-10-19。本文描述当前源码和开发构建，不代表已发布、已安装的新版本。首批工作区、命令片段、目录联动及实验性桌面入口继续见 `工作工具首批使用说明.md`。

## 连接稳定与恢复

- SSH 自动恢复默认开启，可在设置中关闭。状态栏显示恢复状态、倒计时和暂停入口；状态栏、分栏菜单及 `⌘⇧R` 支持手动重连。
- 保持既有 15 秒心跳和三次容错；网络黑洞检测不是瞬时完成，本轮故障注入约 59 秒检测到中断。后台标签不主动断开，唤醒/网络变化不强拆健康连接。
- tmux 重新附着原会话，不重放命令或创建替代会话。普通 Shell 无法保证保留前台任务，主动重连前会确认。
- 自动恢复不弹出密码或指纹窗口；无法静默认证时暂停，手动重连后按正常流程验证。
- “复制连接诊断”只包含时间、事件、PID 和退出状态，可用于继续排查真实网络断线，不包含终端正文或凭据。

## 复制与图片附件

tmux 远端选区复制不再立刻提示“没有本地选区”。Farport 先检查本终端已经完成的剪贴板写入，或短暂等待同步；未确认新同步只给中性说明。仍可以按 Shift 拖选后 `⌘C` 直接复制本地选区。

图片、Finder 文件、拖入附件共用目标绑定。上传和文件复核后各可短暂等待原焦点稳定；同标签重复选择不算切换。真正换标签、继续输入、连接变化、关闭自动插入等仍保留手动确认，不自动回车、不重复发送。不会仅为自动插入而激活后台应用或抢走文本框焦点。

## 远端网页模板

选中远端主机，在“工作工具”中打开“远端网页与服务模板”。保存名称、SSH 主机可访问的目标地址/端口、HTTP 或 HTTPS 和路径，连接后通过本机回环端口打开浏览器。

- 复用现有 SSH 身份及指纹校验，不向网络公开本地端口。
- 模板绑定主机连接配置，禁止 URL 查询参数和片段；路径本身也可能含敏感数据，请勿手动保存令牌。
- 保留 HTTPS 验证：本机回环地址可能与服务证书不匹配，不自动忽略证书错误。网页外链、重定向或另一个端口不保证经过 SSH。
- 关闭面板或终端不会停止独立通道；在通道列表显式停止，或退出 Farport。

## 编辑差异与失败草稿

编辑器可在保存前查看与上次读取/保存版本的变更区域，每侧最多展示 200 行，不是完整的逐 hunk diff。

实际保存失败时，将 UTF-8 编辑内容写入本机私有草稿。重开相同主机、连接、路径及原始文件版本时，可明确恢复；远端已经变化时禁止直接套用，只能复制草稿后核对合并或明确丢弃。未处理旧草稿时不允许保存覆盖。多窗口通过草稿 UUID 避免互相删除/覆盖；成功保存清理本窗口对应的副本。

草稿可能包含敏感正文，保存在私有应用目录；不是加密保险库。超出 512 KiB 的内容不支持此编辑器。草稿落盘失败会明确提示不要关闭编辑器。

## 命令级复制和长任务提醒

普通终端右键菜单提供“复制所选命令全文”和“复制所选命令的输出”。要求 Shell 已输出完整 OSC 133 标记；不会安装 Shell hooks、猜提示符或修改用户配置。只缓存近期完整命令，最多 20 组/总 1 MiB/单组 2000 行；清屏、改写、回收、尺寸变化、跨命令和 tmux 等无法确认边界时拒绝，仍可使用普通选区复制。

长任务提醒默认关闭。开启后，仅明确有开始/结束标记的后台命令和受管理传输运行超过 30 秒才提醒，不用“停止输出”猜完成。使用应用内浮层，应用不在前台时可请求 Dock attention；不在提醒里包含命令正文。
