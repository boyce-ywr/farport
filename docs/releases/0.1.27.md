# Farport 0.1.27（构建 33）正式版

2026-11-17 17:01:40（北京时间）已正式发布为 **Latest**，非草稿、非预发布。正式包、草稿九个附件和公开下载验收均已通过；在线更新验收因本机代理无法连接 GitHub 未完成。

## 修复

- **herdr 里运行 Docker 容器时，附件路径是 Mac 上的而不是容器里的**：herdr 标签中，Farport 直接启动的是 herdr 客户端，原先按普通本机终端处理，粘贴图片后插入的是 Mac 临时目录路径。现在会定位 herdr 当前聚焦的窗格，窗格前台是 `docker exec`/`docker attach`（例如 docker-claude）时，像 tmux 一样上传到容器内并插入容器里的路径。本机与 SSH 主机都适用。
  - 插入前再次核对聚焦的仍是同一窗格、前台仍是同一 docker 进程，变化则不发送；路径经本终端输入，由 herdr 转发给聚焦窗格，括号粘贴按窗格实际状态处理，不自动回车。
  - Cmd+点击 herdr 窗格输出中的路径：普通 Shell 窗格以窗格目录为基准；容器内路径按工作目录和 bind 挂载换算成主机路径后打开。

## 新功能

- **herdr 会话停止、恢复与重命名**（本机与 SSH 主机）：
  - 运行中的会话新增“停止会话…”：结束其中全部进程，保留工作区与分屏布局。
  - 已停止的会话可“恢复…”：在新标签中重启会话，恢复工作区、分屏和各窗格目录；原来运行的命令不重新执行、滚屏不恢复。herdr 默认还会把支持的 Agent 恢复到原来的对话（herdr 配置 `resume_agents_on_restore`）。
  - 已停止的会话可“重命名…”。herdr 官方没有会话重命名命令（截至 0.9.5），Farport 通过移动其数据目录 `sessions/<名称>` 改名：仅在 herdr 0.9.x 上启用，只认 herdr 报告的数据目录，改名前确认目标不存在且目录内有 `session.json`，改名后核对列表。`default` 会话和运行中的会话不能改名。
- Zellij 重命名会等到列表里确实出现新名称再返回，避免紧接着的操作偶尔找不到会话。

功能提交：`c5dca52`（附件）、`60c0b3c`（路径点击）、`791fe2c`（停止、恢复、重命名）。

## 使用边界

- Zellij 窗格里的附件和 Cmd+点击路径仍按普通终端处理：Zellij 的接口拿不到窗格进程，不能可靠识别其中的容器。
- 同一 herdr 会话有多个客户端同时附着时，以 herdr 记录的聚焦窗格为准。
- 重命名依赖 herdr 0.9.x 的数据目录结构；herdr 升级到其他版本后，重命名按钮会提示未验证，待重新实测后再启用。
- **仍为 ad-hoc 签名，未完成 Developer ID 签名和 Apple 公证。** Intel 版只做交叉构建和静态验证，不在真机上运行验证。
