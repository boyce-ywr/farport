# Farport 栖远 0.1.4

## 终端与文件

- 标签包含独立分栏组，切换整组布局，不再固定遗留右栏；保留比例、焦点及终端连接。
- 支持当前分栏内嵌套左右/上下拆分、最大化还原，各分栏有来源标题、焦点边框和文件入口。
- 快捷键：`⌘D` 左右、`⌘⇧D` 上下、`⌘[` / `⌘]` 切换分栏、`⌘⇧Enter` 最大化/还原。
- 多选文件及文件夹后右键批量删除，显示目标与数量；保留并报告失败项，未选项目不受影响。
- 本机登录终端与本机 tmux、每会话独立文件浏览状态、十种主机颜色、双指捏合字号。
- 图片粘贴、文件/文件夹附件和拖拽自动上传至接收机器的私有临时目录，回读校验后插入目标可读路径，不自动回车；不再要求逐次确认上传目录。
- 修复非交互 SSH 的 PATH 不含 tmux 安装目录时无法管理/附着会话。

## 私有 Release 更新

- 应用菜单或设置中“检查更新”，通过已登录的本机 GitHub CLI 读取此私有仓库；不内置 Token。
- 可选择启动时每天检查一次，不自动下载/安装，不强制中断 SSH。
- 下载匹配架构的安装包，验证大小、SHA-256 和 DMG 完整性，再由用户确认打开安装包。

## 安装与边界

- Universal 包含 Apple Silicon / Intel 二进制。运行验收在 Apple Silicon / macOS 27.0.1；Intel 和 macOS 14 真机尚未验收。
- 退出旧版前先保存普通 Shell 的工作。手动替换正在使用的 `Farport.app`，不要在不同 Applications 目录同时保留多个正式版本；配置路径及应用身份保持兼容。
- 旧版没有更新入口的，先安装本版本。安装本版本后可检测未来正式 Release；同版本不会提示升级。
- 目前为 ad-hoc 签名，尚无 Developer ID 签名及 Apple 公证。校验和不是 Apple 身份认证。
- 动态终端白色矩形尚未稳定复现，本版不宣称修复。Claude Code 图片语义读取未单独完成真实模型验收；对端 Codex/tmux 接收验证范围见验证文档。
- 自动上传保证所连接机器可以读取，不自动穿透二次 SSH、容器或其他用户的文件系统。
