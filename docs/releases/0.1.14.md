# Farport 0.1.14（构建 20）正式版

2026-10-21 19:20:29（北京时间）已发布并设为 Latest；九个公开附件回下载校验一致，实际更新服务成功识别 0.1.14、下载 ARM64 包并完成 SHA-256 和 DMG 校验。

本版将已验收的终端标签快捷导航、Agent 会话列表、分屏目录继承和剪贴板策略纳入正式版。发行源码固定为 `a2e623205822cbf47adcdcf8267cf82788a2571d`，与构建 20 预览一致；完整 SHA 同时提供于附件 `SOURCE_COMMIT.txt`。

## 改进

- **分屏继承当前目录**：左右/上下分屏从发起窗格获取目录。本机读取前台进程真实 cwd，tmux 读取原 pane，普通 SSH 使用可信目录报告；不向原终端发送 `cd`，不改变 HOME。目录失效、未知或嵌套容器环境回退默认目录；普通新标签仍默认主目录。
- **快捷切换外层标签**：`⌘⌥←/→` 切换前后标签，`⌘⌥1…8` 定位，`⌘⌥9` 切到最后标签。仅终端焦点生效，不向内部 tmux 发送这些按键，保留文本输入框、组字和弹窗的按键行为。
- **Agent 会话入口**：`⌘⌥J` 或“工作工具 → Agent 会话…”打开当前设备的 Claude Code、Codex、Pi 会话。支持新建、原生会话选择器、切换工作目录和按历史 ID 恢复；在新 PTY 或新 tmux 中执行，不向原 Agent 注入命令。已登记的同会话优先定位，已识别的 tmux Agent 可附着。
- **自动读取跨项目会话**：移除无法选中的历史读取开关；切换 Agent 自动扫描当前目标用户下的全部项目，不再必须先指定目录。展示完整 session ID、名称、工作路径和最后活跃时间，按活跃时间倒排；没有名称显示未命名，时间无法确定时注明文件时间估计。移除固定 200 条截断，包含可识别的 Codex 归档。
- **剪贴板权限可配置**：设置 → 隐私与安全可选“询问 / 始终允许写入 / 禁止”。读取 Mac 剪贴板文本另有独立开关，默认关闭；前台焦点、后台隔离和 1 MiB 上限保留。不会取消附件目标确认或多行粘贴确认，也不会替用户自动开启读取权限。

## 使用边界

- Agent 列表只返回 ID、名称、路径和时间，不返回聊天正文、不改写会话文件、不调用模型；解析时会接触原始会话记录。按本机、SSH 和已确认的本机 Docker 目标隔离，不自动安装 Agent 或 Python。
- 会话扫描保留 60 秒时限、2 MiB 单行和 12 MiB 输出限制；缺 Python、权限不足、未知格式、超时或结果超限会提示失败或列表不完整。JSONL 适配并非三工具完整官方 SDK，恢复命令通过夹具验证，不宣称三工具真实模型上下文均已完成恢复验收。
- 容器附件承接 0.1.13 的已确认本机 Docker 目标支持；远程 Docker、容器内再次 SSH 或切换用户仍不在支持范围。远程 Mac 桌面/VNC 继续为实验功能，真实 Mac 登录和多显示器等验收边界不因本次发布改变。

## 安装和数据

提供 Apple Silicon、Intel、Universal 的 DMG 和 ZIP。保存工作并退出旧版后，以 **Farport.app** 替换正式应用；沿用 `local.sshworkbench.mac` 和 `~/Library/Application Support/SSH Workbench`。预览版配置不会自动覆盖正式版，本次发布不替换用户正在运行的应用。

安装包仍为 ad-hoc 签名，未完成 Apple Developer ID 签名和公证。核对来源与摘要后，按系统或组织的正常流程处理安全提示，不关闭防护。
