# Farport 0.1.12（构建 15）正式版候选

范围：将已经预览验证的终端恢复、复制、附件、编辑和工作工具改进按正式版身份打包，不在这一轮继续添加业务功能。正式发布前仍须完成该候选包的升级、启动、核心回归和下载校验；本文件不代表已经发布。

## 正式版身份与数据

- 应用名称保持 `Farport.app`，Bundle ID 保持 `local.sshworkbench.mac`。
- 数据目录继续使用 `~/Library/Application Support/SSH Workbench`，直接读取旧正式版配置，不改到预览目录。
- 预览版的 `Farport Preview` 数据不自动覆盖或合并到正式版。预览中新增的主机需要用户确认后另行添加或导入。
- 升级前保存工作并退出旧正式版；应用内更新仍需用户确认，不自动关闭现有终端或安装。

## 升级验收

`scripts/check-upgrade.py` 使用真实旧版 ZIP 与新版正式 `.app` 在隔离目录演练应用替换。数据使用旧版格式的合成主机、有效测试指纹和传输记录，偏好键通过进程参数域验证，不修改真实用户偏好，不读取实际主机或钥匙串。

检查正式身份一致、主机和指纹保留、传输身份/路径/进度/条目保留、未完成任务暂停而不自动恢复，以及保存后再次启动读取一致。该测试不宣称已经在用户的真实配置目录执行升级。

## 已知边界

- 远程 Mac 桌面 / VNC 继续标为实验功能，真实 Mac 的账户登录、锁屏、中文输入、多显示器和跨主机凭据隔离尚未完成验收，不因本次正式版发布而改称已通过。
- 仍使用 ad-hoc 签名，未完成 Developer ID 公证。按系统或组织的正常提示核对并允许，不关闭防护或移除安全属性。
- 架构构建、安装检查和实际设备运行验证分别记录；没有实机证据的架构不宣称实机验收。
