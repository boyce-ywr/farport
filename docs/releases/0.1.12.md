# Farport 0.1.12（构建 16）正式版

已于 **2026-10-20 11:47:13（北京时间）** 发布到 GitHub Releases，标签 `v0.1.12`，`draft=false`、`prerelease=false`，并设为 Latest。

本版将此前预览中的连接恢复、复制粘贴、编辑器和工作工具改进纳入稳定版，并新增文件分栏。提供 Apple Silicon、Intel 和 Universal 的 DMG/ZIP；要求 macOS 14 或更新版本。

## 主要改进

- **文件分栏**：`⌘D` 左右分栏、`⌘⇧D` 上下分栏，每栏独立选择本机或 SSH 主机，目录、选择、筛选与排序互不干扰；支持调整大小和最大化。
- **跨主机复制**：源文件列表 `⌘C`，目标栏 `⌘V`，支持同一 Farport 进程的不同窗口。文件/目录拖拽也进入同一传输队列，保留源文件，同名目标仍需确认覆盖。
- **操作隔离**：修复多栏表头串台、隐藏栏截获事件、文本输入框与文件快捷键冲突；主机配置失效或拖入期间目标变化时拒绝误复制。收起预览后不继续下载选中文件。
- **连接恢复**：网络故障退避重试，提供 `⌘⇧R` 手动重连；保留后台心跳容错，网络变化不主动拆除健康连接。认证和主机指纹问题仍等待用户处理，tmux 只恢复原会话，不重放命令。
- **终端剪贴板与附件**：合并 tmux 远端同步和本地复制反馈，避免失败提示覆盖已成功复制；图片/文件上传后等待原终端焦点稳定，再按已选策略插入，不重复插入、不自动回车。
- **编辑与工作工具**：保存前差异预览、失败草稿恢复、工作区恢复、命令片段、可信目录联动、远端网页模板和命令级复制；包含大目录加载反馈及此前预览服务闪退修复。

## 安装与升级

- M 系列 Mac 下载 `Farport-0.1.12-arm64.dmg`，Intel 下载 `Farport-0.1.12-x86_64.dmg`，需要兼容两者可选 `Farport-0.1.12-universal.dmg`。Release 同时提供 ZIP。
- 升级前保存工作并退出旧正式版，将 **Farport.app** 放入“应用程序”。正式身份仍为 `local.sshworkbench.mac`，沿用 `~/Library/Application Support/SSH Workbench`，不会自动合并预览版配置。
- 未完成的传输在升级后暂停，不会自动重启。应用内更新仍需确认，不自动关闭现有终端或安装。
- 校验清单为 `Farport-0.1.12-SHA256SUMS`，可使用 `shasum -a 256 -c Farport-0.1.12-SHA256SUMS` 核对下载。
- 仍为 ad-hoc 签名，未完成 Developer ID 公证。若系统或组织安全软件提示审批，请核对程序后按正常流程允许，不要关闭防护或移除安全属性。

## 已知边界

- Intel 没有真机运行验收；Apple Silicon 的结果不能视为所有设备或 macOS 版本的运行承诺。
- 文件拖拽已验证原生表格行数据、provider 接收链和实际复制内容；构建机没有系统事件投递权限，完整鼠标拖拽手势及落点高亮尚未完成自动化验收。分栏布局不跨重启保存，内部文件引用不支持跨进程或直接拖出到 Finder。
- 远程 Mac 桌面 / VNC 仍为**实验功能**：主机右键“打开远程 Mac 桌面…”通过独立 SSH 通道调用苹果原生“屏幕共享”，不采集桌面密码；Mac 本地授权账户登录、锁屏、中文输入、多显示器及跨主机凭据隔离仍待真机验收，不承诺 Apple ID 登录或苹果高性能模式。
- 网络恢复不保证普通 Shell 前台任务跨断线保留；长任务请使用 tmux。此前隔离目录副本存在无输出终止，具体安全拦截来源未确认；用户打开正式应用后，从相同正式应用位置完成了上述自动化验收，没有修改安全策略。

## English

This stable release adds independent file panes and cross-host copy/paste, alongside SSH recovery, tmux clipboard feedback, attachment auto-insertion, editor drafts, and workspace tools. It keeps the existing Farport application identity and configuration directory. Apple Silicon runtime checks passed; Intel packages were built and structurally verified but not tested on Intel hardware. Remote Mac desktop access remains experimental. Packages are ad-hoc signed and not notarized; follow normal system or organization approval procedures.
