# Farport 0.1.29（构建 35）正式版

2026-11-20 23:51:10（北京时间）已正式发布为 **Latest**，非草稿、非预发布。正式包、草稿九个附件和公开下载验收均已通过；在线更新验收因本机代理无法连接 GitHub 未完成。

## 新功能

- **侧栏主机手动排序**：左侧“我的主机”列表可以调整顺序。
  - 直接拖动主机放到同组另一台主机上，即占用其位置（向下放到其后，向上放到其前），悬停时显示目标框。
  - 也可右键主机选“上移 / 下移 / 移到最前”；已在组内最前或最后时对应项置灰。
  - 只能在同一分组内调整，拖到其他分组的主机上不生效。
  - 顺序直接保存在主机配置（`hosts.json`）中；搜索、编辑主机都不会打乱顺序，新添加的主机排在组末尾。

0.1.28 的“手动排序”作用于“会话”页的会话卡片，而不是侧栏主机列表；这一版补上了侧栏主机排序。功能提交：`867d2d9`。

## 使用边界

- 分组标题的先后仍按名称排序，暂不能手动调整。
- **仍为 ad-hoc 签名，未完成 Developer ID 签名和 Apple 公证。** Intel 版只做交叉构建和静态验证，不在真机上运行验证。
