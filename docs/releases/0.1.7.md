# Farport 栖远 0.1.7

- **返回上一跳目录**：文件工具栏新增返回按钮，位于向上箭头左侧。按实际访问顺序返回，各文件来源分别记住历史；刷新、失败和取消不会添加错误记录。
- **中英文界面**：设置中可选择简体中文、English 或跟随系统，下次启动生效，不自动中断当前连接。文件名、主机名称和终端输出不翻译。
- **音视频在线预览**：按需通过 SSH/SFTP 读取，使用 macOS 原生播放器播放、暂停和拖动进度，不要求完整下载，不自动播放。
- **常见文件高亮**：JSON、XML、Java、Python、JavaScript/TypeScript、Shell、Go、Rust、C/C++、Swift、SQL、YAML、TOML 的只读词法高亮。区分字符串、注释、关键字和数字，保持原始文件内容。

## 使用说明

语言切换请先保存工作，再自行重启应用。界面语言不更改远端 Shell 的语言设置。音视频能否播放取决于 macOS 对实际编码的支持；已验证 WAV 和 H.264 MP4，不承诺所有媒体容器/编码。媒体预览仅开放所选文件，单文件上限 32 GiB；关闭预览会撤销临时访问。

源码高亮不是编译检查，复杂嵌入语法和文件中段的颜色可能不完整。原有编辑保存逻辑不变。

本版仍使用 ad-hoc 签名，未完成 Apple 公证；Intel 未真机运行验收。普通 Shell 的工作请在升级前保存，应用不会替用户自动关闭连接。

## English

- Back navigation follows each file source's visit history, not its parent path.
- Choose English, Simplified Chinese, or System in Settings. Changes apply next launch without interrupting current sessions.
- Stream audio and video on demand with native playback controls; WAV and H.264 MP4 have been tested. Codec support depends on macOS.
- Read-only lexical highlighting for JSON, XML, Java, Python, JS/TS, Shell, Go, Rust, C/C++, Swift, SQL, YAML, and TOML. File contents are never changed by highlighting.

Apple Silicon, Intel, and Universal packages are included. Builds remain ad-hoc signed and are not notarized.
