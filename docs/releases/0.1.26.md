# Farport 0.1.26（构建 32）正式版

2026-11-15 22:03:30（北京时间）已正式发布为 **Latest**，非草稿、非预发布。正式包、草稿九个附件、公开下载和在线更新验收均已通过。

## 改进

- **附件提示条显示耗时**：发送附件时，提示条实时显示各阶段耗时（确认目标、确认容器、上传并回读校验、等待终端焦点、插入前复核、粘贴到终端），完成后在紧凑提示中显示总耗时，悬停可看各阶段明细。总耗时只累加各阶段，不包含等待你选择容器或手动插入的时间。

功能提交：`0f6330c`。

## 使用边界

- 0.1.24、0.1.25 的边界仍然适用：在 Zellij、herdr 窗格里粘贴附件、Cmd+点击路径，暂按普通终端处理。
- **仍为 ad-hoc 签名，未完成 Developer ID 签名和 Apple 公证。** Intel 版只做交叉构建和静态验证，不在真机上运行验证。
