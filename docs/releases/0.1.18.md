# Farport 0.1.18（构建 24）正式版

2026-10-28 21:10:31（北京时间）已正式发布为 **Latest**，非草稿、非预发布。正常构建、正式包、草稿与公开九个附件重新下载、在线更新验收均通过。

## 新功能与修复

- **tmux 松开鼠标后复制**：在 tmux 默认鼠标释放动作清除选区之前读取本次快照，随后按 ⌘C、顶部按钮或复制菜单仍可复制。支持等待中的复制与重复复制；不会读取旧全局缓冲，也不会未经明确复制就主动改写 Mac 剪贴板。输入、失焦、连接和剪贴板变化会使快照失效；最多两秒转发鼠标释放，始终保留 Shift 拖选的本地通道。
- **Docker 图片附件提速**：单文件采用有界内存快照直传，省去重复本机暂存；目录、权限和哈希校验按批合并；通过已确认的本机 Unix socket 读取 Docker 服务身份，减少 CLI 启动开销。保留用户身份、容器状态、原窗格、内容和插入前复核，不降低图片画质。
- **按实时 tmux 会话进入工作区**：已配置主机启用“连接时优先打开 tmux 工作区”后，默认连接先检测远端：没有会话时询问新建，允许修改名称；只有一个直接进入；多个必须选择。取消不擅自创建，错误不当作空列表，失效会话和过期请求不会替换成别的目标；显式普通终端和分屏入口保持原行为。

功能提交：`bd2b57d`、`e83923a`、`714af98`。发行源码固定为 **`643c5f361f64926204006115f3ca8e2fe1f20094`**，须与 `v0.1.18` 标签和 `SOURCE_COMMIT.txt` 一致。

构建流程已恢复：系统 CLT 直接构建仓库根包；SwiftTerm 1.20.0 的 86 个原始文件和许可证按精确 Git blob 校验，版本信息由上游原生成器显式生成。运行时代码、Metal 资源及语言模式保持不变，不依赖临时验证包或失效的插件宿主。

## 性能与使用边界

- 同工具链 Debug 小图对照：已绑定 Docker 容器约从 7 秒降至 4.5–4.6 秒；结合前一轮优化，相比原先约 18 秒明显缩短。正式 Release 包本次中英文测得已绑定插入 **3.744 / 3.523 秒**，首次确认 **8.330 / 8.124 秒**。该数据不代表任意大小图片、网络或所有机器的固定时延，也不包含 Agent 后续读取和识别。
- 只支持应用管理的 tmux 当前选择与本次拖选快照；手动嵌套 tmux/SSH、无快照的已取消选择，以及不能安全独立读取的旧 tmux 配置，仍使用 Shift 拖选。未修改远端全局配置。
- Docker 附件仍限已确认的本机 Unix socket，不放开 TCP/SSH Docker 端点；权限不足、内容变化或目标变化时拒绝插入。不会自动回车。
- 提供 Apple Silicon、Intel、Universal 的 DMG/ZIP，应用身份保持 `local.sshworkbench.mac`，沿用原配置目录；测试使用隔离数据，不替换已安装应用。
- **仍为 ad-hoc 签名，未完成 Developer ID 签名和 Apple 公证。** 安装须遵循 macOS 或组织规定，不关闭系统防护。Intel 只做交叉构建和静态验证，不代表真机运行通过；此前独立复制安装目录的运行限制不因构建通过而自动视为解决。
