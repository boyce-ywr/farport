# Farport 0.1.20（构建 26）正式版

2026-10-29 准备发布。正式包验收、草稿附件、公开下载和在线更新尚待核验，不等同于已公开发行。

## 修复与改进

- **Shift 拖选可以正常取消和重新开始**：终端程序（tmux、Claude Code 等）接管鼠标时，普通单击会取消 Farport 的本地选区，同时照常把点击发给程序；新的 Shift 拖选总从点击处开始，不再沿用上一次的起点。
- **粘贴图片时“正在确认目标”更快**：直接读取 Docker 的 context 配置（读不到时回退 docker 命令），只检查原窗格所在的容器，刚识别完成时不重复校验服务；本机容器状态改经已确认的 Docker socket 接口读取，减少 docker 命令启动开销。安全核对项（容器身份、启动状态、接收用户、内容哈希、插入前复核）保持不变。

功能提交：`de841d6`。发行源码 SHA 在打包后补齐，须与 `v0.1.20` 标签和 `SOURCE_COMMIT.txt` 一致。

## 性能与使用边界

- 开发构建小图测量：本机“正在确认目标”首次由 3.2 秒降到 1.4 秒，已绑定 0.6 秒；本机“摄取到插入”首次由 5.6 秒降到约 3.5 秒。远端 Docker（回环 SSH）约 4.6–5.0 秒、已绑定约 3.3–3.5 秒，主要耗时在 SSH 往返和容器内写入。不代表任意大小图片、网络和机器的固定时延。
- 0.1.19 的边界仍适用：远端 macOS 上含空格的容器名或工作目录可能识别失败；`set-clipboard on` 在 tmux 服务重启后需要再次确认；未在实际 mac-mini 上验证。
- **仍为 ad-hoc 签名，未完成 Developer ID 签名和 Apple 公证。** Intel 只做交叉构建和静态验证，不代表真机运行通过；新复制安装目录的运行限制不在通过声明内。
