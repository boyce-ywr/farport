# Farport 0.1.14（构建 19）本地开发预览

本版本承接已发布 0.1.13（18），增加外层 Tab 快捷导航和 Agent 会话入口。只生成独立预览，不替换正式应用、不自动创建 GitHub Release 或修改 Latest。

## 新功能

- `⌘⌥←/→` 上下外层标签，`⌘⌥1…8` 定位，`⌘⌥9` 最后一个；保留 `⌘⇧[/]` 及原有分栏/工作页组合。限定终端焦点，文本框、组字与弹窗不抢按键。
- `⌘⌥J` 或“工作工具 → Agent 会话…”打开当前本机、SSH 或明确 Docker 目标；可在指定目录新建三工具会话、打开原生会话选择器、开终端或按历史 ID 恢复。
- 历史默认关闭，用户确认后读取受限 JSONL 元数据。最近列表有最多 200 条、扫描时长/目录/大小上限，不读取或返回完整会话；部分文件头同行含正文，读取后过滤，不应称为完全不接触正文。无 Python/未知格式保留原生选择器，工具未安装则提示，不自动安装。
- 恢复固定原工具数据根、会话 ID/文件及 cwd，在新 PTY 或新 tmux 执行，不向原终端发命令。当前窗口中已登记的同会话优先定位，已识别的 tmux Agent 可附着。退出/取消/失效处理明确，不把“进程启动”宣称为“模型上下文恢复成功”。

- 当前 ARM64 Release 通过 **2669 项核心断言**、**996 条英文资源**检查；独立会话/导航核心检查 42 项。19 组 SSH 集成、两个隔离 SSH 的三工具启动计划/真实 cwd，以及独立容器目标用户、真实 TTY cwd、缺 Python 降级与原有附件安全检查通过。
- 新包经 LaunchServices 完成中英文非前台模型检查：新建 tmux、启动参数/目录、原终端零输入、运行登记、只附着不重跑、取消和失效 tmux 拒绝。两种语言均正常退出，不把模型模式当作原生按键验收。
- 最早中英文前台版本通过按键和面板检查；后续安全收尾时构建机为 `CGSSessionScreenIsLocked=Yes`，最终包内前台验收尚未完成。不得把非前台模型测试或早期截图当作新版前台验收。
- 本轮不运行真实用户的历史恢复、不调用模型；三工具执行计划用夹具校验。完整实际工具会话验收及未识别格式请按原生恢复入口处理。
