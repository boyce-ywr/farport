# Farport 0.1.14（构建 20）本地开发预览

本版本承接已发布 0.1.13（18），增加外层 Tab 快捷导航和 Agent 会话入口。只生成独立预览，不替换正式应用、不自动创建 GitHub Release 或修改 Latest。

## 构建 20 追加改进

- 分屏继承发起窗格当前目录：本机从前台进程读取真实 cwd，tmux 从原 pane 获取，普通 SSH 使用可信目录报告；左右/上下菜单与快捷键复用该流程，不向原终端发送 `cd`。未知、失效或嵌套容器环境回退默认目录；本机 HOME 不变。
- Agent 列表不再通过可回退的授权开关，也不再要求指定启动目录。切换工具自动加载该设备用户下的全部项目，展示名称、完整 session ID、路径、最后活跃时间，按事件时间倒序；移除固定 200 条截断，包含可识别的 Codex 归档。无法确定时间时标记文件时间估计，不把目录名冒充会话名。
- 新建操作的目录输入放入单独折叠区，不影响列表。空目录、无匹配、读取失败、缺 Python、超时/未知格式有明确提示；超 60 秒或结果超过安全输出上限明确显示列表不完整，不声称无边界全量读取。
- 设置 → 隐私与安全新增终端剪贴板写入策略，可选“始终允许写入，不再询问”；文本读取单独开关默认关闭，提示可能读取密码的风险。前台焦点、后台隔离、1 MiB 上限保留；图片文件仍走附件、多行粘贴确认不变。

## 新功能

- `⌘⌥←/→` 上下外层标签，`⌘⌥1…8` 定位，`⌘⌥9` 最后一个；保留 `⌘⇧[/]` 及原有分栏/工作页组合。限定终端焦点，文本框、组字与弹窗不抢按键。
- `⌘⌥J` 或“工作工具 → Agent 会话…”打开当前本机、SSH 或明确 Docker 目标；可在指定目录新建三工具会话、打开原生会话选择器、开终端或按历史 ID 恢复。
- 打开会话面板即按所选 Agent 自动读取跨项目元数据，不再让“授权开关弹窗失败”阻止列表。解析时会接触会话记录但只传回 ID、名称、路径、时间，不传聊天正文、不写数据库、不调用模型。无 Python/未知格式保留原生选择器，工具未安装则提示，不自动安装。
- 恢复固定原工具数据根、会话 ID/文件及 cwd，在新 PTY 或新 tmux 执行，不向原终端发命令。当前窗口中已登记的同会话优先定位，已识别的 tmux Agent 可附着。退出/取消/失效处理明确，不把“进程启动”宣称为“模型上下文恢复成功”。
