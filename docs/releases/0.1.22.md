# Farport 0.1.22（构建 28）正式版

发布进行中：正式包构建与验收完成后，先上传为草稿，核对附件后再公开。

## 新功能

- **终端里的路径可以直接点开**：按住 Cmd 悬停时路径会出现下划线，Cmd+点击后，目录会在"文件"页打开，文件会在终端页上弹出预览。预览里的"在文件页定位"会打开所在目录并选中该文件，方便继续编辑或下载。Ctrl+点击或右键菜单里也有"在文件中打开"。
  - 路径按终端所属主机解析：远端 SSH（含 tmux）在远端找，本机终端在本机找。`~` 按目标主机的 HOME 展开。
  - 相对路径（如 `docs/decisions.md`）的基准目录依次为：点击时 tmux 窗格或本机前台进程所在的目录、Shell 上报的目录（OSC 7）、目标主机 HOME。使用第一个存在的。
  - 能识别 `file.swift:12:4` 这类带行号的写法（暂不跳转到行），会去掉结尾的全角标点。中文紧贴路径（如"已记入docs/a.md"）时，原文找不到会去掉中文前缀再试。OSC 8 的 `file://` 链接只接受空主机、localhost 或当前主机名。
  - 路径不存在时会提示，不打开任何内容。tmux 窗格或本机终端的前台是 ssh、docker、sudo 等时，路径不属于当前主机，会拒绝打开。

## 修复

- **图片预览被裁切**：长截图等竖长图片在预览中按原始尺寸显示，下半部分看不到。现在默认缩放到刚好完整显示在预览区内（小图不放大）。双指缩放后可以拖动查看局部，双击恢复。

功能提交：`a79cc4d`。

## 使用边界

- 从终端打开的预览只包含被点击的文件，不能用 ← → 切换同目录的其他文件；需要时用"在文件页定位"。
- 不是 tmux 的普通 SSH 终端里，如果又手动 SSH 到了第三台机器，Farport 识别不出来，路径仍会按当前主机查找。容器内 Agent 终端暂不支持打开路径。
- **仍为 ad-hoc 签名，未完成 Developer ID 签名和 Apple 公证。** Intel 版只做交叉构建和静态验证，不在真机上运行验证。
