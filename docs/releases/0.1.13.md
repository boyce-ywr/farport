# Farport 0.1.13（构建 18）正式版

2026-10-20 21:17:35（北京时间）已发布并设为 Latest，九个附件回下载校验一致，实际更新服务成功识别 0.1.13、下载 ARM64 包并完成摘要/映像校验。

本版包含本机 tmux 启动目录修复及容器附件流程。源码固定为 `b736f52`，完整 SHA 见附件 `SOURCE_COMMIT.txt`。后续 Tab 快捷键与 Agent 会话面板不包含在本次安装包中。

## 改进

- 本机新 tmux 会话从用户主目录启动；新窗口和分割继承目标窗格目录，已有会话不强行切目录。
- 本机 tmux 中直接 `docker exec -it` / 可交互 `docker attach` 支持图片和文件附件。第一次选择并确认原容器、context/socket 和接收用户，按该用户写入私有临时目录，内容和权限校验后插入容器内路径，不自动回车。
- 支持本机 context、`DOCKER_HOST=unix:///…` 以及 `docker -H/--host unix:///…`，修复早期预览误拦截本机 DOCKER_HOST。固定 socket、daemon ID、完整容器 ID/启动状态及原窗格进程，容器重启、目标变化或文件变化时停止发送。
- 同一目标可复用确认；不自动提权、不重建容器、不改挂载。暂不支持远程 TCP/SSH Docker、Compose、Podman、容器内再次 SSH 或切用户；缺少工具、权限不足时明确提示。

## 安装和数据

提供 ARM64、Intel、Universal 的 DMG 和 ZIP。保存工作并退出旧版后，用 **Farport.app** 替换正式应用；沿用 `local.sshworkbench.mac` 和 `~/Library/Application Support/SSH Workbench`。预览版配置不会自动覆盖正式版。

仍为 ad-hoc 签名，未 Apple 公证；安全提示按系统或组织的正常流程核对允许，不关闭防护。远程 Mac 桌面/VNC 继续为实验功能，真实 Mac 登录、多显示器等边界不因本次发布改变。
