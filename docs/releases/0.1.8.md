# Farport 栖远 0.1.8

本次交付为 **构建 11**。本地测试过构建 9/10 的用户也需要更新；崩溃报告中的版本应显示 `0.1.8 (11)`。

## 稳定性修复

- 修复音视频/网页预览传输中关闭服务导致的 `Semaphore object deallocated while in use` 闪退。
- 一并处理预览接入与停止竞态、半包请求、断连取消、限流槽位恢复及超时回调持有连接的问题。
- 增加 50 轮并发关闭、20 轮半包析构、20 轮异常连接恢复、30 轮接入/停止竞态、10 轮隔离 SSH 并发读取，以及真实 120 秒超时和 20 次 AVPlayer 切换回归。

## 编辑与界面

- 语言设置立即切换并保存，不需要重启；终端连接和编辑草稿保留。
- 文本编辑器增加保存、撤销、重做、剪切、复制、粘贴和全选；Cmd+S 保存后保持打开并轻提示，连续保存仍检查外部文件修改。
- 传输记录、磁盘列表和系统信息布局更紧凑。已完成的本机目标或源文件可在 Finder 中定位。
- 右下角显示本机时间，修复 loading 导致监控页面反复上下移动。

## 主机监控

- 新增“监控”页（⌘6）：概览、进程、网络与端口、系统与用户信息。
- 查看 CPU、RSS/Working Set 内存、进程 PID/用户/运行时间、各网卡上下行速度、监听端口与可用的进程归属、磁盘挂载点及系统硬件信息。
- 默认约两秒刷新，可暂停或改为 5/10 秒；离开页面停止。仅在内存中保留最近十五分钟的 CPU/内存曲线。
- 只读、免安装，不自动提权。权限或工具不足时显示不可用，不用 0 或整机网速冒充缺失数据。

## 终端交互

- 默认右键菜单：复制、粘贴、全选、清除选择。粘贴继续走原有附件上传/多行确认规则。
- 设置中可开启“tmux 终端右键使用 tmux 菜单”；Shift＋右键回到普通菜单。仅识别应用附着的 tmux。首次开启会话 mouse 前确认，不改全局配置；同一会话的其他客户端也会受影响。
- 附件新增全局自动插入开关及每主机覆盖。自动模式校验成功且原目标未变就插入；手动模式上传后等待点击。均不自动回车，保留目标变化保护。
- 修复终端自动查询回包被误当成用户输入，从而阻止附件自动插入。Cmd+V、右键粘贴、Finder 拖入统一处理；真实输入及切换目标仍触发保护。
- tmux 右键使用专用菜单事件，前台程序接管鼠标时也能打开默认 tmux 菜单，不改远端绑定。

## 平台与限制

- macOS 和隔离 Linux 采集已实际验证。Windows 监控提供 PowerShell/CIM 适配，但本轮未完成监控真机验证；Termux 按 Android 权限降级，尚未完成监控实机验证。
- Windows OpenSSH 原生 CMD 终端、中文输入输出、连接探测、SFTP 和 CP936 错误解码已在一台 Windows 主机实测。原生 Windows Shell 的 tmux 页明确提示不支持，普通终端可用；不会擅自配置 WSL、安装软件或更改默认 Shell。该主机还曾发生连接重置，不能把网络问题说成已由这次编码修复解决。
- 进程级带宽不在当前免安装能力内。端口 PID 取决于权限/工具；Linux proc 回退可显示端口但不提供 PID 归属。磁盘为文件系统用量，不是磁盘健康监测。
- 不提供结束进程、重启系统、服务管理或后台告警。

提供 Universal、Apple Silicon 和 Intel 三种 DMG/ZIP。Intel 未真机运行，安装包仍为 ad-hoc 签名、未 Apple 公证。升级前保存工作并自行退出旧版。

## English

Build 11 fixes the preview-server shutdown crash and related connection lifecycle races. It also adds immediate language switching, save-without-closing editing, compact transfer and monitoring layouts, Finder actions, and a status-bar clock. Clipboard images/files now auto-insert after verification without treating terminal protocol replies as typing. Native Windows CMD input/output, SSH/SFTP and legacy Chinese error decoding have live validation; native Windows shells do not provide this tmux manager. Monitoring is read-only, with the platform limits above. Intel runtime testing and Apple notarization remain outstanding. Terminal pet/image-protocol support is not part of this build.
