# Farport 0.1.25（构建 31）正式版

2026-11-15 21:35:22（北京时间）已正式发布为 **Latest**，非草稿、非预发布。正式包、草稿九个附件、公开下载和在线更新验收均已通过。

## 新功能

- **本机终端可设置默认打开方式**：“设置 → 本机终端 → 本机终端打开方式”可选普通终端、tmux、Zellij 或 herdr，默认普通终端，升级后行为不变。
  - 侧栏“本机终端”、⌘⇧T、标签栏和侧栏菜单中的“新建本机终端”、文件页“打开终端”按此设置打开。
  - 进入规则同主机“连接时进入”：没有会话先询问新建，一个直接进入，多个让你选择。
  - 侧栏按钮只复用类型符合设置的本机标签；选了多路复用器时，菜单另有“新建本机普通终端”。
  - 分屏、会话页“打开普通终端”和工作区恢复不受影响，仍按原方式打开。
- **会话确认框可改为打开普通终端**：本机和远端主机的确认框都新增“打开普通终端”按钮。工具未安装或版本过低时显示原因，不会悄悄退回普通终端。

功能提交：`a288876`。

## 使用边界

- 0.1.24 的边界仍然适用：在 Zellij、herdr 窗格里粘贴附件、Cmd+点击路径，暂按普通终端处理，还不识别窗格内的 Docker 容器。
- **仍为 ad-hoc 签名，未完成 Developer ID 签名和 Apple 公证。** Intel 版只做交叉构建和静态验证，不在真机上运行验证。
