# Farport 栖远 0.1.5

## 安装包按芯片选择

- **Apple Silicon（M 系列）**：`Farport-0.1.5-arm64.dmg`
- **Intel Mac**：`Farport-0.1.5-x86_64.dmg`
- 两个 DMG 内都叫 `Farport.app`，但分别只有对应架构。在线更新优先匹配架构；旧版也可识别这两个安装包。

## 工作台改进

- 文件类型列及五列三态排序（升序/降序/默认），文件夹优先，各来源独立保留排序状态。
- 顶部空白双击填满当前屏幕可用区，再次双击恢复原位，不进入独立全屏空间。
- 修复 Termux 等设备一个异常 UTF-8 文件名导致整页目录加载失败：显示正常文件并提示跳过数量，不用替代字符构造可操作路径。递归传输和删除仍严格检测，避免静默漏文件。

- 标签拖放排序、右键移到最前/最后；新增可搜索、切换和关闭的全部标签列表，排序不影响分栏或连接。
- 同名传输不再直接失败：显示冲突并等待覆盖确认，批准后继续原任务。目录合并保留额外文件，类型不兼容和符号链接不会被覆盖。
- 一键清除失败/已取消记录或全部已结束记录；不删除文件与断点，不影响进行中、暂停和待确认任务。
- 主机弹窗重新排版：分区表单、统一留白、对齐的用户/端口、带文字的颜色网格及固定底部动作。
- 文件预览支持拖动调整宽度；PDF 原生翻页/缩放；HTML 页面与源码切换。
- “在浏览器打开”通过本机回环 HTTP 代理按需读取远端 HTML/CSS/图片，支持相对链接与锚点，不需要在远端安装 Web 服务。默认禁用脚本，可信报告可显式启用本目录脚本；外部资源仍受限。

## 边界

- HTTP 代理只开放当前 HTML 所在目录及其子目录，不自动代理父目录、绝对根路径、CDN 或后端 API。链接包含临时授权信息，请勿分享；停止服务或退出应用后失效。
- PDF 内嵌上限 32 MiB，HTTP 单资源上限 256 MiB；远端主机离线时不能继续读取未加载内容。
- ARM 已运行验收；Intel 完成独立构建和签名检查，不等于 Intel 真机验收。两包目前都是 ad-hoc 签名，尚未完成 Apple 公证。
- 当前运行的普通 Shell 不会被自动关闭，安装时请先保存工作并自行重启。旧版动态白块问题仍未稳定复现，不在本版修复声明中。
