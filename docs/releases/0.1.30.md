# Farport 0.1.30（构建 36）正式版

发布状态：草稿，附件核对中。

## 修复

- **远程桌面连 macOS 屏幕共享时不能复制粘贴**：macOS 自带的屏幕共享服务端不响应第三方客户端的标准 VNC 剪贴板消息（Apple“屏幕共享”app 使用私有扩展），所以 Farport 里本机和远端之间复制粘贴双向都不生效。现在远端是 macOS、且桌面就在这台 SSH 主机上（桌面地址为 `127.0.0.1`/`localhost` 或主机地址本身）时，改为经 SSH 在远端执行 `pbcopy`/`pbpaste`：
  - 点进远程桌面时，本机复制的文本写入远端剪贴板，在远端 ⌘V 即可粘贴；
  - 离开远程桌面回到本机时，远端复制的文本读回本机剪贴板，在本机 ⌘V 即可粘贴；
  - 仍受工具栏“文本剪贴板同步”开关控制，只同步文本，单次不超过 1 MiB，中文正常。
  - 详见 [问题复盘](../issues/2026-11-21-远程桌面连macOS屏幕共享时剪贴板不同步.md)。功能提交：`618c24f`。

## 使用边界

- 要求 SSH 登录的用户就是远端屏幕当前登录的用户；不一致时会提示，并改回 VNC 协议同步（macOS 下可能仍不生效）。
- 桌面经 SSH 转到其他机器（地址不是这台主机）时，仍按 VNC 协议同步。
- Linux 等其他 VNC 服务端的剪贴板同步方式不变。
- **仍为 ad-hoc 签名，未完成 Developer ID 签名和 Apple 公证。** Intel 版只做交叉构建和静态验证，不在真机上运行验证。
