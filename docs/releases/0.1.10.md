# Farport 0.1.10（构建 13）

**预发布验证状态**：Debug 和独立 Release 程序通过下述本机/SSH/tmux 交互检查及 2109 项核心断言；本机打包应用启动仍有 SIGKILL，未完成稳定的安装版运行验收。三个 DMG 已构建并校验，但暂不替代 0.1.9 稳定版。当前运行的应用未被覆盖或自动关闭。

## 终端复制

- 每个终端分栏新增复制、粘贴及剪贴板权限菜单；Cmd+C / Cmd+V 可直接使用。
- Shift 拖选强制使用本地选区，不被 tmux 或前台程序的鼠标捕获接走。有本地选区时，右键优先显示普通复制菜单。
- 修复无本地选区时复制清空原剪贴板的问题；改为提示操作方法。
- 仅在内容确实写入 Mac 剪贴板并校验后提示成功。终端协议复制被拒绝或在后台发起时给出明确反馈，可选择“允许并复制刚才的内容”，无需再次选中。
- 授权仅针对当前连接，重连后重置；远端读取 Mac 剪贴板仍禁止。多行粘贴确认、附件上传及不自动回车规则保留。

## 进程表排序

- PID、进程、用户、CPU、内存、运行时间六列均支持表头点击，循环升序、降序、默认，并显示方向箭头。
- CPU、内存、运行时间按原始数值排序；缺失值始终末尾，同值按 PID 稳定排序。默认是 CPU 降序。
- 监控刷新、搜索不会重置排序；文件表原有三态排序继续保留。

验证包含中英文六列表头点击、箭头与刷新保持，本机/SSH/tmux 复制与原生文本框粘贴，权限拒绝、后台保护及无效协议数据。此前宠物和预览闪退修复继续包含。

提供 Apple Silicon、Intel、Universal 三种 DMG/ZIP；Intel 未新增真机运行验证，签名仍为 ad-hoc，未 Apple 公证。

## English

Terminal panes now offer Copy, Paste, and clipboard permission controls. Shift-drag creates a local selection even in mouse-aware tmux/TUI applications. Copy without a selection preserves the existing clipboard; success feedback is shown only after verifying the Mac clipboard write. Blocked protocol writes can be explicitly allowed and copied without selecting again. Permission resets on reconnect; clipboard reads remain blocked. All six process-table headings cycle ascending, descending, and default order, with numeric comparison, missing values last, and order retained during refresh and filtering. Earlier fixes and Codex pet support remain included.
