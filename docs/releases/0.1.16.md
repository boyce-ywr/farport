# Farport 0.1.16（构建 22）正式版

2026-10-25：发布准备中，尚未公开。完成正式包、下载校验和在线更新验收后更新本页。

## 新功能与修复

- **文件双击预览**：图片、文本、HTML、PDF 和音视频可在灯箱式弹窗中查看。支持放大或还原预览区域、Esc 关闭；左右箭头或方向键切换同类型文件，与文件列表选中项同步。
- **HTML 关联资源**：侧栏和弹窗支持同级目录、子目录中的图片、CSS、SVG 等相对引用。修复多资源同时请求时额外连接被直接断开的问题，保持最多四路读取并将其余请求排队。中文、空格文件名及查询参数可用；可信页面可手动允许本地脚本、模块和 JSON 数据读取。
- **文件剪切移动**：文件列表支持 ⌘X 和右键剪切，多选后在目标分栏按 ⌘V 移动；剪切项淡化显示，粘贴前不会删除源文件。已入队的剪切引用自动消费，避免重复移动。
- **同机复制与移动加速**：完整连接配置一致的端点采用原生 `cp` / `mv`，避免文件内容经过 Mac 中转。保留覆盖确认与安全暂存；目录合并保留目标额外条目，跨端点移动先校验内容再逐项删源。
- **批量移动后刷新**：修复目录读取期间后续刷新请求被丢弃的问题，合并排队刷新，两侧列表及时反映已完成的文件变化。
- **附件粘贴与插入**：PNG 原样写入暂存文件，减少重复解码和重编码；TIFF 在后台转码。缓存目标临时目录，减少重复请求。上传后短暂切换窗口或页面，可在六秒等待窗口内返回原终端继续自动插入；新输入、连接或配置变化仍阻止自动发送，不自动回车。

对应功能提交：`9b77125`、`89ca49f`、`ff82b23`。发行源码以 Release 的 `SOURCE_COMMIT.txt` 和 `v0.1.16` 标签为准。

## 安装与安全边界

- 计划提供 Apple Silicon、Intel、Universal 各自的 DMG 和 ZIP。正式应用身份仍是 `local.sshworkbench.mac`，沿用原配置目录；发布验收使用隔离数据，不读取或覆盖真实用户配置。
- **ad-hoc 临时签名，未完成 Developer ID 签名和 Apple 公证。** 请核对来源和 SHA-256，遵循 macOS 或组织规定的安装流程；不要关闭系统防护，组织策略禁止时应停止安装。
- Intel 包只做交叉构建、架构与静态签名检查，不代表 Intel 真机运行验收。旧版记录的新复制目录启动限制将在本次验收中单独记录，不能以 `open` 返回零替代实际启动通过。
- HTML 只允许当前报告目录及子目录，不开放目录外文件、符号链接、绝对 `file://` 地址或外部 CDN。脚本默认关闭，只有明确信任后才执行。
- 移动停止或失败时保留源、目标和 `.swb-*.move` 暂存目录，从原传输任务继续。已经完成的部分不会自动撤销，请勿重新剪切、删除暂存内容或在移动期间编辑两端文件。
- 不支持 POSIX Shell 的端点继续使用 SFTP；本版不新增 Windows 或其他未实测平台的兼容性承诺。
