# Farport 0.1.13（构建 17）本地预览

范围：本机 tmux 主目录修复、本机 tmux 内 Docker 附件目标确认与安全复制。尚未发布 GitHub Release；终端 Tab 新快捷键和 Agent 会话面板仍是已确认的后续计划，不包含在此包中。

## 使用

- 独立名称 `Farport Preview.app`，Bundle ID `local.sshworkbench.preview`，与正式版并存；配置目录为 `~/Library/Application Support/Farport Preview`，不自动合并正式版资料。
- 本机 tmux 管理页附着后，进入可识别的本机 `docker exec -it` / 可交互 `docker attach`，再粘贴图片或文件。首次确认原容器和用户，随后同一进程/容器未变化时复用绑定，自动插入受设置、焦点和输入状态保护。
- 附件写入容器私有暂存目录，按接收用户校验内容，插入容器路径但不回车；首版依赖容器内基础命令，不支持远程 Docker、Compose、Podman、容器内二次 SSH/su。
- 新本机 tmux 会话从主目录启动，新窗口/分割继承目标窗格目录；旧会话保留原目录。
