# Farport 0.1.17（构建 23）正式版

2026-10-28 准备发布；正式公开前须完成下述验收，不以构建成功或草稿附件代替发布。

## 修复

- **主动复制 tmux 当前选区**：Farport 管理的 tmux 会话没有本地选区时，⌘C、顶部复制按钮和右键复制会主动读取当前远端选区，不再只等待剪贴板同步。关闭 OSC52 的隔离环境也覆盖此路径。
- **保留选择和复制模式**：不退出 tmux 复制模式，不拿历史缓冲区或其他窗格的内容冒充当前选择；读取结束后清理本次临时缓冲。
- **保护异步剪贴板写入**：新输入、连接重置、窗口失焦、活动状态变化、新复制请求或其他程序修改剪贴板时，放弃迟到结果。空内容、非法编码和超限内容不会覆盖已有剪贴板。

功能修复提交为 `6f56fc6`；根因及专项覆盖见 [问题复盘](../issues/2026-10-27-tmux复制只等待同步.md)。本版沿用 0.1.16 的文件预览、剪切移动和附件优化，不改变文件传输语义。

## 使用边界

- 只主动读取 Farport 管理的 tmux 当前选区。普通终端内手动嵌套的 tmux、已经取消的选区，以及无法安全独立读取选择的旧 tmux 配置，仍请按住 Shift 拖选后再按 ⌘C。
- 提供 Apple Silicon、Intel、Universal 的 DMG 和 ZIP；正式身份为 `local.sshworkbench.mac`，沿用原配置目录。验收使用隔离配置，不读取或替换已安装的应用及真实用户配置。
- **仍为 ad-hoc 签名，未完成 Developer ID 签名和 Apple 公证。** 请核对来源和 SHA-256，遵循 macOS 或组织规定的安装流程，不要关闭系统防护。
- Intel 仅交叉构建、架构和静态签名检查，不代表 Intel 真机运行验收。此前独立复制目录的 LaunchServices 启动验收没有通过，本版不宣称已解决；正式包运行验证使用原始 `dist/Farport.app`。
