## VNC / 远程 Mac 桌面

选中远端主机，在“工作工具”中选择“打开远程 Mac 桌面”。当前通过独立 SSH 通道打开苹果原生“屏幕共享”窗口，不是内嵌桌面。

认证交给系统客户端处理，目标是 Mac 已授权的系统账户；Farport 不采集桌面密码。真实 Mac 的原生账户登录、锁屏、中文输入、多显示器及跨主机凭据隔离仍需目标设备验收，继续标为实验功能。

运行日志、截图与测试主机配置保留在忽略的 `.test/` 中，不进入安装包或公开仓库。
