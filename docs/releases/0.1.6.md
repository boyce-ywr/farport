# Farport 栖远 0.1.6

## 工作空间更大

- 精简顶部主机信息和导航，将常用入口合并到一行工具栏。
- 左侧主机栏可折叠/展开，快捷键 `⌘⌥S`；偏好在重启后保留。
- 搜索终端内容按需展开（`⌘F`），已发送附件提示压成单行。

## 标签与文件

- 修复终端标签实际拖不动：支持鼠标按下并拖至目标标签、目标高亮、Esc 取消；原生鼠标事件回归验证多次往返排序。
- 文件来源标签独立排序，不改变终端分组、焦点或连接。
- 支持双击打开指向目录的符号链接，例如 Termux `storage/shared`；普通文件链接支持只读预览，失效/无权限有明确提示。
- Markdown 原生格式预览、源码切换、编辑器并排实时预览与安全保存；不会执行 HTML 或自动加载远端图片。

## 三种安装包

- **Universal 通用版**：`Farport-0.1.6-universal.dmg`
- **Apple Silicon（M 系列）**：`Farport-0.1.6-arm64.dmg`
- **Intel Mac**：`Farport-0.1.6-x86_64.dmg`

在线更新优先选择匹配当前芯片的独立包，通用版作为回退。安装前保存普通 Shell 中的工作并自行退出旧版；不会自动结束远端 tmux。

ARM 已运行验收；Intel 与通用包的 Intel 部分完成构建、架构及签名检查，未 Intel 真机运行。当前仍为 ad-hoc 签名，未 Apple 公证；历史动态白块问题未稳定复现，不列为本版已修复。
