# Farport 0.1.28（构建 34）正式版

发布状态：草稿，附件核对中。

## 新功能

- **会话页卡片手动排序**：tmux、Zellij、herdr 的会话卡片可以调整顺序。
  - 拖动卡片放到同组另一张卡片上即占用其位置（向下放到其后，向上放到其前），悬停时显示目标框；也可用卡片“…”菜单的“上移 / 下移 / 移到最前”。
  - 顺序按“主机 × 工具”分别保存在本机，只能在同一主机、同一工具内调整。“连接时进入”和本机终端的会话选择框也按此顺序列出。
  - 按会话名记录（tmux 的会话 ID 在服务重启后会变）；在 Farport 中重命名的会话保持原位置；新会话排在最后；已结束的会话在下次调整顺序时从记录中移除，不在刷新时删除，避免一次刷新失败清空顺序。已退出 / 已停止的会话不参与排序。

功能提交：`67f0f75`。

## 使用边界

- 在其他终端或命令行中重命名的会话，会被当作新会话排到最后。
- 顺序只保存在本机，不同步到其他 Mac。
- **仍为 ad-hoc 签名，未完成 Developer ID 签名和 Apple 公证。** Intel 版只做交叉构建和静态验证，不在真机上运行验证。
