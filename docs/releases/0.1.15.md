# Farport 0.1.15（构建 21）正式版

2026-10-22 13:33:06（北京时间）已发布为 Latest，非草稿、非预发布。安装及签名限制仍保留，见下文。

本版交付 tmux 剪贴板保护与文本粘贴修复。发行源码固定为 `07204d9904a746025383ca8ce802bdd7315d38aa`；剪贴板修复提交为 `9f92ef5`。

## 本次修复

- **避免空白复制覆盖剪贴板**：拒绝 tmux/终端经 OSC 52 发来的纯换行、空格或制表符内容，不再把已有剪贴板替换成看起来空白的内容。有效文本的首尾空白仍保留；手动本地选区复制不受影响。
- **粘贴使用确认时的内容**：触发粘贴时只读取一次文本，确认框打开期间剪贴板变化不会替换实际发送的内容。取消不发送；保留 bracketed paste 标记，避免把粘贴文本转换成增强键盘事件。
- **多行确认可以单独关闭**：设置 → 隐私与安全新增“粘贴多行文本前确认”，默认开启，关闭后不再弹出该确认框。它与终端读写剪贴板权限独立，设置立即生效并保存。关闭后文本中的命令可能立即执行。

图片与文件仍走原有附件处理和目标校验，不放宽终端读取权限、前后台隔离或附件确认。0.1.14 的分屏目录继承、跨项目 Agent 会话列表、标签快捷导航与 Docker 附件支持均保留。

## 安装与已知边界

- 提供 Apple Silicon、Intel、Universal 的 DMG 和 ZIP。保存工作并退出旧版后，以 **Farport.app** 替换正式应用；沿用 `local.sshworkbench.mac` 和 `~/Library/Application Support/SSH Workbench`，预览版配置不会自动覆盖正式版。
- **仍为 ad-hoc 临时签名，未完成 Developer ID 签名和 Apple 公证。** 本版没有解决签名信任问题。核对来源和 SHA-256 后，按 macOS 或组织规定的正常流程处理首次打开提示；不要关闭系统防护，组织策略禁止时应停止安装。
- **新复制目录启动仍有未解决的限制。** 构建机上，新版 ZIP 解压副本和 DMG 复制副本经 LaunchServices 启动均无输出；旧版 0.1.14 的同类副本也失败。原始正式 `.app` 完成下述回归，但不能据此宣称所有新安装路径均已验收通过。
- 用户现场“tmux 新窗口粘贴变复制”的完整时序尚未捕获。两个独立缺陷已复现并修复，但本版不自动退出 tmux 复制模式，不宣称复制模式中的所有粘贴行为都已改变。
- Intel 包通过构建、架构、签名与包内容检查，未在 Intel 真机运行；不外推 Apple Silicon 运行结果。
