# Farport 0.1.11（构建 14）预发布

发布类型：Prerelease，不设为 Latest，不通过稳定版更新检查推送。仅提供 Apple Silicon ARM64，要求 macOS 14 或更新版本。

## 安装与配置

- 下载 `Farport-0.1.11-preview-arm64.dmg` 或 `.zip`。
- 应用名称是 **Farport Preview.app**，可以与正式版 Farport 并存；不要手动改名覆盖正式版。
- 预览配置保存在 `~/Library/Application Support/Farport Preview`，不会自动迁移旧版主机、传输或工作区记录。首次打开没有原来的主机列表是预期行为，可自行添加或导入 SSH 配置；旧数据没有被删除。
- 校验文件为 `Farport-0.1.11-preview-SHA256SUMS`，可执行 `shasum -a 256 -c Farport-0.1.11-preview-SHA256SUMS` 验证下载文件。
- 仍为 ad-hoc 签名，未完成 Developer ID 公证。公司安全软件可能提示执行审批，请核对程序并按正常流程允许，不要关闭防护或移除安全属性。

## 本轮改进

- SSH 中断恢复：修复运行中手动重连等待不到退出回调的问题；解码原始退出状态，网络故障退避重试，认证/指纹问题暂停交给用户验证。新增状态栏和 `⌘⇧R` 手动恢复入口。
- 后台连接：保留心跳容错，减少后台调度影响；网络变化不主动拆除健康连接，tmux 恢复只附着原会话，不重放命令。
- tmux 复制反馈：合并远端同步与本地复制提示，避免“没有本地选区”覆盖实际复制成功；仍以 Mac 剪贴板写入回读为准。
- 图片附件：上传后短暂等待原终端焦点稳定，同标签重复点击不再误判切换；真正换目标、新输入或连接变化仍要求确认，不重复插入、不自动回车。
- 编辑器：增加保存前差异预览和失败草稿；恢复时同步原生编辑框，外部文件变化时禁止直接套用旧草稿。
- 工作工具：工作区恢复、命令片段、可信目录联动、远端网页模板，以及依赖明确 Shell 标记的命令级复制和默认关闭的长任务提醒。
- 文件导航：大目录加载有及时反馈，减少重复枚举。此前文件预览生命周期、终端复制及进程表排序修复继续包含。

## 远程 Mac 桌面 / VNC（实验）

入口为 **左侧远程主机右键 → 打开远程 Mac 桌面…**，或顶部主机选择器旁四格“工作工具”菜单。未配置远程主机或当前选中本机终端时，工具菜单入口不可用。

默认通过独立 SSH 通道打开苹果原生“屏幕共享”窗口，不是内嵌桌面。认证由系统客户端处理，目标是 Mac 已授权的系统账户，而非 Apple ID/iCloud；Farport 不采集桌面密码。

**真实 Mac 的账户登录、锁屏、中文输入、多显示器及跨主机凭据隔离尚未完成验收**，请按实验功能使用。已验证的 SSH 转发和界面不代表桌面登录已通过；不承诺苹果高性能模式。

## English

This is an **Apple Silicon prerelease**, not the latest stable release. Install **Farport Preview.app** alongside Farport. It uses a separate configuration directory and does not automatically migrate saved hosts or transfers. The build improves SSH recovery, tmux clipboard feedback, attachment auto-insertion, editor draft recovery, and workspace tools. Remote Mac desktop access opens Apple's Screen Sharing client through SSH and remains **experimental**: real Mac account authentication and related desktop workflows have not yet completed acceptance testing. The build is ad-hoc signed and not notarized; follow your organization's normal approval process without disabling security protections.
