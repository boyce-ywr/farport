# 产品截图

这些图片由 `scripts/capture-readme.sh` 从 Farport 的真实原生界面捕获，使用隔离 SSH 容器与演示文件。

| 图片 | 内容 |
| --- | --- |
| `terminal.png` | 同一标签内操作两台 SSH 主机 |
| `tmux.png` | 查看持久会话、窗口和目录 |
| `transfers.png` | 已完成的跨主机复制与同名覆盖确认 |
| `markdown.png` | 文件列表与 Markdown 格式预览 |
| `html.png` | 从远端读取并预览 HTML 报告 |

画面中的主机名、用户、回环地址和文件均为演示数据。不包含真实服务器配置、密码、私钥、访问令牌或私人对话。仅保留审查后的 PNG，不在此目录存放原始调试记录。

保持图片原貌；允许等比缩放，不用后期替换界面文字来宣称尚未实现的功能。
