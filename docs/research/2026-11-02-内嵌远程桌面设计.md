# 内嵌远程桌面（VNC/RFB）设计

日期：2026-11-02。状态：设计已与用户逐项确认，尚未实现。本设计取代 [2026-10-19 调研](2026-10-19-Mac远程桌面设计建议.md)中“桌面交给系统屏幕共享 App”的首期方向；系统屏幕共享保留为备用入口。

## 已确认的决定

| # | 主题 | 决定 |
| --- | --- | --- |
| 1 | 远端范围 | macOS 屏幕共享为第一优先，体验对标系统 App；同一客户端完整支持标准 RFB 服务（Linux、Windows 上的 VNC）。不做 RDP；手机不专门适配。 |
| 2 | 网络 | 默认经 SSH：RFB 直接跑在专用 `ssh -W` 子进程的标准输入输出上，不开本地端口；远端即 SSH 主机时目标为 `127.0.0.1:5900`，跳板时显示完整目标关系。可按主机显式改为直连，会话中始终标识“未加密”。不做自动选择。 |
| 3 | 实现方式 | Swift 自研 RFB 客户端：Raw、CopyRect、ZRLE、Tight（JPEG）、Hextile；zlib 用系统 libz，JPEG 用 ImageIO；画面写入两块 IOSurface 轮流交给 CALayer（由系统合成器直接用 GPU 显示，只复制脏区域）；ARD（security type 30）用 CommonCrypto 加大数运算。参考 RFC 6143、noVNC、TigerVNC 的公开行为，不复制 GPL 代码；保持 MIT 和“只依赖 SwiftTerm”。 |
| 4 | 界面位置 | 作为终端页的一种标签（如“mac-mini · 桌面”），与终端同组；可弹出为独立窗口、原生全屏、拖到其他显示器，也能收回为标签；可同时开多个。入口：主机右键菜单、主机详情、标签栏“+”。保留“用系统屏幕共享打开”。 |
| 5 | 凭据 | Farport 自己的登录框，支持 ARD 用户名密码、VNC 口令、无认证；可勾选保存到 Farport 自己的钥匙串条目（按主机 + 桌面目标 + 用户名区分）。不复用 SSH 账号、不读取系统屏幕共享的条目；失败后清除本次密码并重新询问，不自动重试；不进日志、URL、命令行；主机设置可清除。 |
| 6 | 快捷键归属 | 桌面获得焦点时普通组合键（含 ⌘C/V/W/Q/Z）全部发给远端；Farport 本地操作用 ⌃⌥ 前缀（⌃⌥F 全屏、⌃⌥Esc 释放键盘、⌃⌥W 关闭标签，可改）。系统级快捷键默认留在本地；可选“捕获系统快捷键”，开启时才申请辅助功能权限，仅在桌面窗口获得焦点时生效并显示状态。 |
| 7 | 修饰键映射 | 远端 macOS 原样映射；远端 Linux/Windows 默认 ⌘→Ctrl（⌃ 仍为 Ctrl，Super 经右 ⌘ 或 ⌃⌥ 菜单发送）。远端类型自动判断，可按主机修改，工具栏可临时切换。 |
| 8 | 中文输入 | 默认远端输入法（获得焦点时绕过本地输入法）；工具栏“本地输入法”开关：确认的文字优先用 Unicode keysym 发送，不支持时提示后改用“写入远端剪贴板 + 粘贴”。macOS 支持情况实测后定默认值。 |
| 9 | 文本剪贴板 | 获得焦点时双向自动同步；Extended Clipboard 用 UTF-8；只支持旧 Latin-1 时，遇中文提示不支持，不发乱码。按主机“自动 / 每次询问 / 关闭”，单次 1 MiB；图片和富文本不经 RFB。 |
| 10 | 文件 | 走已有 SSH/SFTP：拖到画面或桌面内 ⌘V 粘贴 Finder 文件 → 上传到远端目录（默认 `~/Desktop/Farport 传入/`，可改），传输中心显示进度，完成后可在远端 Finder 显示；工具栏侧边栏复用文件面板供下载。仅直连无 SSH 时不提供并说明。 |
| 11 | 分辨率与缩放 | 默认适应窗口等比缩放，可切 1:1；正确处理 Retina；服务端支持 ExtendedDesktopSize 时远端分辨率跟随窗口（可关）；macOS 不支持则缩放；多显示器可选查看全部或单块。 |
| 12 | 性能与画质 | IOSurface 双缓冲、只复制脏区域；连续更新扩展，否则流水线请求；光标伪编码本地绘制；按服务端选 Tight/ZRLE/CopyRect；“自动 / 清晰 / 均衡 / 流畅”，自动档按带宽与延迟调 JPEG 质量和压缩级别；后台解码。目标：局域网 1080p 下鼠标与输入无明显滞后，以实测为准。 |
| 13 | 鼠标与触控板 | 左、右、中键（⌥+点击）；平滑滚动按像素累计换算滚轮，方向跟随本地“自然滚动”；拖拽、双击、长按原样转发；不做鼠标锁定。 |
| 14 | 会话功能 | 工具栏：只读、特殊键（Ctrl+Alt+Del 等）、截图、重连、画质、键盘映射、剪贴板开关、文件侧边栏、弹出/全屏。状态栏：延迟、帧率、带宽、编码、是否经 SSH。断线自动重连 3 次，间隔递增，需重新认证时停下询问；切到其他标签时暂停画面更新。 |
| 15 | 不纳入范围 | 声音、Apple 高性能模式、Apple Account 认证、macOS 其他用户登录或虚拟显示器等私有选项、屏幕录制、RDP。需要时用系统屏幕共享入口。 |
| 16 | 测试 | Docker 跑 Linux 夹具（TigerVNC、x11vnc）自动覆盖协议、编码、认证、剪贴板、调整分辨率、断线；本机 Mac 屏幕共享已开启（5900 返回 `RFB 003.889`），用回环 SSH 测 ARD 认证和画面；mac-mini 最终验收由用户完成。 |
| 17 | 分期 | 第 1 期：核心协议、Raw/CopyRect/ZRLE/Tight、三种认证、SSH 通道、标签与窗口、键盘映射、鼠标、文本剪贴板、适应缩放、状态栏。第 2 期：调整分辨率、连续更新、自动画质、文件拖放与侧边栏、本地输入法、捕获系统快捷键、多显示器。第 3 期：只读、截图、特殊键、重连打磨、中英文界面完整验收。每期结束交付用户试用后再进入下一期。 |

## 已知事实

- 现有实现：`ScreenSharingRelay` 经 `ssh -W` 在 127.0.0.1 开临时端口，`ScreenSharingView`（sheet）调用 `com.apple.ScreenSharing` 打开 `vnc://`；`ScreenSharingEndpoint` 校验目标地址。
- 项目为 MIT 许可，唯一第三方依赖为 SwiftTerm；LibVNCClient 为 GPL，不采用。
- 本机 macOS 屏幕共享服务返回协议版本 `RFB 003.889`（Apple 特有）。
